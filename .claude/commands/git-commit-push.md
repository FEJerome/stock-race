# Git 提交与推送命令

**核心任务：** 将当前 Git 工作树中的所有变更提交至指定分支（默认 `develop`），并推送至远程仓库。

## 执行流程

### 1. 设置目标分支
目标分支：`${ARGUMENTS:-develop}`

### 2. 检查状态
- 确认当前目录是 Git 仓库
- 检查是否存在未提交的更改

### 3. 切换并更新分支
- 切换到目标分支
- 拉取远程最新更改

### 4. 分析变更
分析工作树中的变更，包括：
- **代码** (`src/` 等目录)
- **文档** (`docs/`, `.md` 文件等)
- **测试** (`test/` 等目录)
- **配置** (`package.json` 等文件)
- **资源** (`assets/` 等目录)

### 5. 生成提交信息
生成符合以下标准的提交信息：
- 简明扼要，突出核心改动
- 包含变更类型（功能、修复、文档、测试等）
- 长度控制在70字符以内

### 6. 提交变更
- 添加所有变更到暂存区
- 使用生成的提交信息进行提交

### 7. 推送到远程
- 将提交推送到远程目标分支
- 确认推送结果

## 错误处理
- 如果不是 Git 仓库，提供清晰错误信息
- 如果没有变更可提交，提示用户
- 如果分支切换或推送失败，提供解决建议
