# 智能体问答指令

**指令：** 专注于回答用户的问题，不打断当前正在进行的操作，不新建会话，保持最小依赖原则。

## 核心原则

1.  **专注问答**：智能体专注于用户的问题进行回答，保持回答的专业性和准确性
2.  **不打断操作**：如果智能体正在执行其他任务，ask-model指令不打断当前操作，智能体在完成当前操作后回答问题
3.  **最小依赖**：不依赖环境变量配置、不新建会话、不改变当前工作状态
4.  **保持上下文**：基于当前会话上下文进行回答，不需要重新建立项目理解
5.  **灵活工具使用**：根据问题需要，智能体可以使用适当工具（包括Read、Grep等）来获取信息，但不进行修改操作

## 执行模式

### 1. 问答处理流程
当用户发出ask-model指令时：
1. 智能体识别到ask-model指令和用户的问题
2. 如果智能体当前正在执行其他操作（如文件编辑、命令执行等），继续完成当前操作，不中断
3. 完成当前操作后，专注于用户的问题进行回答
4. 回答时保持专业、准确、简洁
5. 回答完成后，回到之前的任务状态

### 2. 信息获取策略
根据问题的性质，智能体可以：
- 使用现有知识直接回答
- 如果需要项目特定信息，可以使用Read、Grep等工具查看相关文件
- 避免使用Write、Edit等修改工具，保持只读模式
- 保持回答基于当前项目上下文

### 3. 最小依赖实现
- **无环境变量**：不需要任何环境变量配置
- **无新建会话**：在当前Claude Code会话中处理
- **无状态改变**：不改变智能体的当前工作状态
- **无复杂配置**：保持简单的指令-响应模式

## 使用方式

```bash
# 直接提问
ask-model "什么是股票市场的最佳投资策略？"

# 在开发过程中穿插提问
ask-model "刚才修改的那个文件，它的主要功能是什么？"

# 技术咨询
ask-model "React和Vue在性能方面有什么主要区别？"
```

## 回答原则

1.  **专业准确**：基于事实和技术规范进行回答
2.  **简洁明了**：避免冗长，直接回答核心问题
3.  **有针对性**：根据问题的具体性提供相应深度的回答
4.  **保持礼貌**：始终保持专业和礼貌的态度
5.  **明确边界**：对于不清楚的问题，明确说明限制

## 指令执行
请回答用户的问题：`$ARGUMENTS`

回答时应遵循上述核心原则，保持专业、准确、简洁，不打断当前正在进行的操作。
