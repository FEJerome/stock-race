## 一、项目概览

### 1.1 项目信息

| 项目 | 内容 |
|------|------|
| 小程序名称 | Stock-Race AI基金经理 |
| 版本号 | 1.0.0 |
| 版本代码 | 100 |
| 开发框架 | UniApp 3.x + Vue 3 + TypeScript |
| UI组件库 | uView Plus |
| 状态管理 | Pinia |

### 1.2 项目定位

- **角色扮演**：用户扮演"投资总负责人"，受"投资董事长"委托管理基金
- **核心玩法**：聘任AI基金经理进行虚拟股票投资
- **竞赛元素**：收益率排行榜比拼
- **教育意义**：学习投资知识，体验投资乐趣
