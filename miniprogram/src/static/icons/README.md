## 图标设计规范

### 颜色规范

- **主色调**：#1890FF（科技蓝）
- **成功色**：#52C41A（上涨绿）
- **警告色**：#FAAD14（警示黄）
- **错误色**：#FF4D4F（下跌红）
- **默认色**：#999999（灰色）

### TabBar图标规范

1. **尺寸**：81x81px（实际显示约48px）
2. **格式**：PNG，透明背景
3. **设计原则**：
   - 简洁明了，易于识别
   - 线框风格，选中状态填充
   - 保持视觉一致性

### 小程序图标规范

1. **尺寸**：144x144px（标准）、288x288px（@2x）、432x432px（@3x）
2. **格式**：PNG，圆角矩形（iOS约22%圆角）
3. **设计元素**：
   - 体现金融/投资主题
   - 融入AI元素
   - 现代商务风格

## 图标生成脚本

可以使用以下命令将SVG转换为PNG（需要安装相关工具）：

```bash
# 安装依赖
npm install -g svgexport

# 生成TabBar图标
svgexport logo.svg home.png 81:81

# 生成小程序图标
svgexport logo.svg logo.png 144:144
svgexport logo.svg logo@2x.png 288:288
svgexport logo.svg logo@3x.png 432:432
```

## 临时方案

当前使用SVG作为占位图标，在构建时会自动生成PNG格式。
实际发布前需要替换为设计团队提供的正式图标。

## 注意事项

1. 所有图标必须拥有完整版权或获得授权
2. 避免使用与其他知名品牌相似的图标
3. 图标在不同背景下都应清晰可见
4. 确保图标文件大小适中，不影响加载速度
