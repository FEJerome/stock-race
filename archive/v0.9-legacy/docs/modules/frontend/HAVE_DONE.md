# Frontend 模块 - 已完成功能记录

## 模块概述

**模块名称**: Frontend (React + TypeScript + Vite)
**主要职责**: Web用户界面、实时行情展示、AI账户管理UI、交易界面
**服务端口**: 3000
**通信方式**: HTTP REST + WebSocket (通过 Backend 中转)
**状态**: ✅ 核心功能已完成，测试待补充

## 潜在风险与注意事项

### 🔴 高风险

1. **AI对话功能缺失**
   - 影响：阻塞AI账户创建核心流程
   - 建议：优先实现，或与Backend协调接口

2. **零测试覆盖**
   - 影响：代码质量无法保障，回归成本高
   - 建议：补充核心功能单元测试

### 🟡 中风险

3. **缓存参数误用**
   - 位置: `market.service.ts:483` - `sortOrder`被误用为搜索词
   - 影响：可能导致排序功能异常
   - 建议：修复参数映射

4. **WebSocket消息处理性能**
   - 位置: `useWebSocket.ts:145-181`
   - 影响：大量消息时可能导致UI卡顿
   - 建议：添加消息队列和限流机制

### 🟢 低风险

5. **模拟数据混合**
   - 部分降级数据使用美股代码（AAPL/MSFT等）
   - 建议：统一使用A股数据
