<!-- AUTO-TASK: BEGIN TAI-P1-002 -->
### TAI-P1-002: 游客数据适配
- **自动化任务**: TAI-P1-002
- **状态**: ⏔ 阻塞
- **优先级**: 🟠 P1-高
- **描述**: Backend 将游客数据从 Redis 迁移到 PostgreSQL 后，Trading AI Service 需要适配查询游客账户
- **技术方案**:
  1. 账户查询适配：查询 ai_accounts 时检查 is_guest 和 guest_session 状态
  2. 决策上下文构建：为游客账户构建决策上下文（持仓、历史决策）
  3. 游客 Token 识别：识别 Backend 传递的游客标识，支持游客账户决策
- **验收标准**:
  - [ ] 已过期游客账户返回 AccountExpiredError
  - [ ] 决策逻辑与正式用户一致
  - [ ] Token 识别正确
- **测试需求**:
  - TC-GUEST-001: 游客账户查询测试
  - TC-GUEST-002: 游客决策上下文构建测试
  - TC-GUEST-003: 游客 Token 识别测试
- **阻塞原因**: 等待 Backend 完成 G-001~G-003
