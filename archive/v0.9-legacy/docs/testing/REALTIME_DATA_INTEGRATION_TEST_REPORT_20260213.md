## 3. 发现的关键问题

### 🔴 严重问题（影响生产）

**1. Redis缓存配置错误**
- **现象**: 连接 `localhost:6379` 失败
- **原因**: Docker容器内应使用服务名 `redis:6379`
- **影响**: 无分布式缓存，数据仅存内存，服务重启丢失
- **修复**: 修改环境变量 `REDIS_URL=redis://redis:6379`

**2. 历史数据未持久化**
- **现象**: TimescaleDB表为空
- **原因**: 采集的数据未写入数据库
- **影响**: 无法获取历史K线，无法计算技术指标
- **修复**: 检查数据写入逻辑，确保实时数据同时入库

### 🟡 中等问题

**3. Tushare数据源未配置**
- **现象**: 缺少API Token
- **影响**: 少一个数据源冗余
- **修复**: 配置TUSHARE_TOKEN环境变量

**4. 数据源间歇性故障**
- **现象**: 第2次采集返回None
- **影响**: 可能影响用户体验
- **修复**: 加强多源故障转移测试
