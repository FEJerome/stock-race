## 🚀 部署流程

### 快速部署
```bash
# 1. 克隆项目
git clone <repository-url>
cd stock-race

# 2. 配置环境变量
cp .env.production.example .env.production
# 编辑 .env.production 文件

# 3. 启动服务
./start-prod.sh up-build

# 4. 验证部署
./start-prod.sh health
```

- **前端应用**: http://localhost:3000

## 🔒 安全建议

## 🐛 已知问题和限制

### 当前限制
1. **端口冲突**: 生产环境和开发环境不能同时运行（端口冲突）
2. **构建依赖**: 需要稳定的网络连接下载Docker镜像
3. **资源需求**: 需要至少8GB内存
4. **存储需求**: 数据库数据会持续增长

### 解决方案
1. **端口配置**: 可以通过环境变量修改端口号
2. **镜像缓存**: 可以在本地构建和缓存Docker镜像
3. **资源监控**: 使用监控工具跟踪资源使用
4. **数据清理**: 配置数据保留策略
