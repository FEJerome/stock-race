# 业务逻辑优化方案

**文档类型**：实现文档 - 业务逻辑调整与优化计划

**创建者**：首席架构师
**版本**：1.0.0
**关联任务**：根据用户批注，修正系统业务逻辑偏差，优化9个关键功能点

## 📋 问题概述

### 当前系统业务逻辑偏差
当前系统设计为：**用户直接操作股票交易**，AI账户作为辅助工具
正确业务逻辑应为：**用户创建AI账户**，AI自主操作股票交易，用户只查看结果

### 核心偏差点
1. **交易功能**：用户直接买卖股票 ❌
2. **持仓管理**：用户直接持有股票 ❌
3. **AI账户角色**：辅助工具而非主体 ❌
4. **模型选择**：包含无法提供的模型 ❌

## 🎯 优化目标清单

### 1. 用户模块增加注册功能 ✅ **新增**
**目标**：实现用户注册功能，支持用户名、密码、密码验证
**业务价值**：提供干净的测试账号，无前置数据
**实现方案**：
- 后端：新增 `/api/auth/register` 端点
- 前端：在登录页面添加注册表单
- 数据库：扩展用户表验证逻辑

### 2. 彻底实现历史数据和市场状态 ✅ **完善**
**目标**：完善历史数据API和市场状态判断
**业务价值**：提供完整的历史数据查询和市场状态信息
**实现方案**：
- 数据服务：完善历史数据查询接口
- 前端：优化市场状态显示组件
- 缓存：优化历史数据缓存策略

### 3. 修正交易订单管理业务逻辑 ✅ **已完成**
**目标**：移除用户直接交易功能，改为AI自主操作
**业务价值**：符合AI股票竞赛平台核心逻辑
**实现方案**：
- 后端：修改交易API，只允许AI账户操作
- 前端：移除用户交易页面，改为AI账户交易监控
- 权限：用户只能查看，不能直接交易

### 4. 修正持仓管理业务逻辑 ✅ **已完成**
**目标**：用户不直接持有股票，只查看AI账户持仓
**业务价值**：用户通过AI账户间接参与股票交易
**实现方案**：
- 后端：修改持仓API，关联AI账户而非用户
- 前端：持仓页面改为AI账户持仓汇总
- 权限：用户只能查看自己AI账户的持仓

### 5. 修正投资组合管理业务逻辑 ✅ **已完成**
**目标**：投资组合针对用户的各个AI账户
**业务价值**：用户管理多个AI账户的投资组合
**实现方案**：
- 后端：修改投资组合API，按用户聚合AI账户数据
- 前端：投资组合页面展示用户所有AI账户汇总
- 计算：实现跨AI账户的盈亏计算

### 6. 修正AI账户模型选择 ✅ **已完成**
**目标**：只支持deepseek和GLM模型（4.7, 4.6, 4.5）
**业务价值**：使用可测试的API，避免无法提供的模型
**实现方案**：
- 前端：修改AI账户创建表单，只显示可用模型
- 后端：验证模型类型，只允许指定模型
- AI服务：确保deepseek和GLM适配器正常工作

### 7. 确保AI交易决策真实执行 ✅ **完善**
**目标**：AI决策真实操作买卖，生成简短操作理由
**业务价值**：实现AI自主交易的核心功能
**实现方案**：
- AI服务：完善决策服务，调用真实交易API
- 交易服务：支持AI账户的自动交易
- 日志：记录AI决策理由和执行结果

### 8. 整合AI分析功能 ✅ **已完成**
**目标**：AI分析整合进AI交易决策
**业务价值**：分析作为决策的一部分，不独立存在
**实现方案**：
- 移除独立的AI分析功能
- 将分析逻辑整合到决策服务中
- 前端移除AI分析页面

### 9. 暂缓排行榜功能开发 ⏳ **已推迟**
**目标**：待其他模块功能完善后再开发
**业务价值**：集中资源完成核心功能
**实现方案**：
- 标记排行榜功能为待开发
- 保留基础数据结构
- 后续按优先级开发

## 🔧 技术实现方案

### 数据库结构调整
```sql
-- 当前：用户直接关联交易和持仓
users → trades
users → portfolios

-- 调整后：用户通过AI账户间接关联
users → ai_accounts → trades
users → ai_accounts → portfolios
```

### API接口调整
1. **交易API** (`/api/trades`)
   - 移除用户直接创建交易的功能
   - 只允许通过AI账户创建交易
   - 用户只能查看自己AI账户的交易记录

2. **持仓API** (`/api/portfolios`)
   - 关联AI账户而非用户
   - 用户查看自己AI账户的持仓
   - 移除用户直接操作持仓的功能

3. **AI账户API** (`/api/ai-accounts`)
   - 增强模型选择验证
   - 添加虚拟人民币金额字段
   - 添加股票操作提示词字段

### 前端页面调整
1. **交易页面** (`Trading.tsx`)
   - 改为AI账户交易监控页面
   - 显示AI账户的实时交易状态
   - 移除用户直接交易表单

2. **AI账户页面** (`AIAccounts.tsx`)
   - 修改模型选择器，只显示deepseek和GLM
   - 添加虚拟人民币金额输入
   - 添加股票操作提示词输入

3. **持仓页面** (待创建)
   - 创建AI账户持仓汇总页面
   - 显示各AI账户的持仓和盈亏

### AI服务调整
1. **模型适配器**
   - 确保deepseek和GLM适配器正常工作
   - 移除或禁用其他模型适配器
   - 添加模型版本选择（4.7, 4.6, 4.5）

2. **决策服务**
   - 整合分析功能到决策流程
   - 生成简短操作理由
   - 调用真实交易API执行操作

## ⚠️ 风险与挑战

### 技术风险
1. **数据库迁移**：现有数据需要迁移到新结构
2. **API兼容性**：前端需要适配新的API接口
3. **AI服务稳定性**：确保deepseek和GLM API稳定

### 业务风险
1. **用户体验**：功能调整可能影响用户习惯
2. **数据一致性**：迁移过程中数据一致性保障
3. **测试覆盖**：确保所有场景测试充分

### 缓解措施
1. **分阶段实施**：逐步调整，降低风险
2. **数据备份**：实施前完整备份数据
3. **回滚计划**：准备快速回滚方案
