# V3 S4 AI 经理人与历史穿越概念说明

> 状态：S4 设计闸第 3 件的概念候选稿，2026-10-29 第三轮返修；待院院核审与御主终审，不授权 S4 实施。
>
> “衡一”是单一 AI 股票经理人的演示身份，不是新模型、新 Agent 或真实基金经理。对话为预写脚本，B/C 只消费 S2 synthetic golden，不代表真实 Kimi 实时工作或真实行情。

## 1. 核心概念

用户不是面对一台回测机器，而是**雇佣一位 AI 股票经理人，派他穿越回过去的某个市场**。

首屏主张：**“雇一位 AI 股票经理人，送他回到过去的市场。”**

角色名：**衡一 / HENG YI**。角色只负责把用户意图整理成规则、按确认后的规则接受历史检验，并依据事件复盘。角色感不能改变交易与数据语义，不能包装成自主决策、实时逐日调用模型或收益承诺。

## 2. 四环节与三幕映射

| 环节 | 用户动作 | 原型表达 | 契约落点 |
|---|---|---|---|
| 01 招聘 | 选择“谨慎梳理”或“指标直达”的面试风格，开始面试 | 同一位衡一，两种预写对话路径；不做多模型／多经理人 | 对话只生成声明式 StrategyDraft |
| 02 穿越 | 选择市场、资产与历史区间，核对执行假设 | 目的地默认 CN A 股、六日 synthetic golden；US/JP 仅愿景并禁用 | RunSpec、DataSnapshot、warmup、执行 profile；模型不可写 |
| 03 围观 | 看衡一在当时如何形成信号、买入、承受回撤、卖出 | 故事章节＋共享 cursor＋可展开“当时依据”抽屉 | 完整 RunEvent[] 先算定，剧场只读投影 |
| 04 复盘 | 问“当时为什么”，阅读穿越成绩单 | 预写规则问答、人话回读、四指标与证据链 | Report、订单、fills、rejections、费用、digest、compare |

A 对应招聘／面试与穿越准备，B 对应围观工作，C 对应复盘与版本比较。四环节是叙事层，不新增模型、资产或交易能力。

## 3. 点时数据与“不能偷看未来”

“穿越者不能偷看未来”不是虚构超能力设定，而是点时数据契约的用户语言表达。

1. 在某个 `tradingDate`，经理人只能使用该时点契约允许可见的 observation、指标状态和账户上下文。未来 bar、未来公司行动和未发布信息不得参与当前判断。
2. 指标需要 warmup 时，不足段保持 unavailable；无法满足要求就阻断，不能为了故事连续而补 0、缩短 warmup 或引用未来值。
3. 当日收盘形成的信号与下一 session 的执行必须按引擎事件顺序呈现。例如本 golden 在 2024-01-01 收盘形成买入意图，2024-01-02 才发生成交；不能讲成 1 月 2 日预知全天走势后买在最低价。
4. 完整 Run 在打开剧场前已经算定。播放、暂停、加速和拖动 cursor 只改变只读投影，不给经理人新增信息，不重跑策略，不改变账本、eventDigest 或 reportDigest。
5. 停牌、缺失、stale 和拒绝原因不得被故事掩盖。没有证据时用 `null + reason` 或失败诊断，不编一个“经理人当时判断”。

首屏角色台词与 B 的固定提示统一为：**“他只知道那天及之前的事。”** B4 的“问他当时依据”只展开真实 `reasonCodes/inputRefs/payload/hash`，不是实时模型解释。

## 4. 招聘与面试边界

- Demo 只有衡一，不提供多模型或多经理人入口。
- 招聘简化为“选面试风格 → 开始面试”：谨慎梳理进入新手白话路径，指标直达进入 MACD/KDJ 参数路径。
- 面试沿用 [对话式策略私教引导脚本](v3-s4-dialogue-guide.md)。只引导表达、不荐股；对话最终收敛 AST，经过校验、权威回读和 expectedDigest 确认。
- “衡一认为”“衡一决定”只能作规则执行的故事化简称。模型不直接下单、不自主修改 RunSpec、不逐日决策。
- 预写对话不产生新 Run。B/C 的 fixed golden 与当前面试草稿保持独立工作轴。

## 5. 围观与复盘表达

### B：围观工作

先讲“哪天买入、哪天经历回撤、哪天退出”，再提供价格、事件泳道、权益与回撤。每个故事章节都能定位真实 seq；用户问“当时为什么”时打开事件证据，而不是生成一段无法核验的散文。

本 golden 的三章：

- 1 月 2 日：执行前一日买入意图，以 10.01 买入 100 股，费用 5.01。
- 1 月 4 日：收盘权益从前一日 2193.99 降到 1893.99；当天 exit=true，形成次日卖出意图。
- 1 月 5 日：执行前一日 intent-2，以 9.99 卖出 100 股，费用 5.51。

### C：复盘对话与成绩单

“问衡一”是预写规则复盘，不是实时模型聊天。回答必须引用当前 Run 的事件、日期、数值和原因；没有证据时明确说没有，不补心理活动或市场因果。

人话成绩单先于四指标呈现，但不替代四指标、详细层、compare 对齐检查与 digest。六个 synthetic session 不能外推为真实投资能力，不荐股、不承诺未来收益。

## 6. 丰富度装饰的开放边界

职级体系、荣誉馆、更多经理人等只作概念点缀，必须标“暂未开放”。不得显示虚构等级晋升、收益排名、奖章成就或更多可选经理人来暗示已开放能力。主行动始终只有开始面试衡一与围观固定 golden。

## 7. 不变的安全与契约边界

- 不接入实盘，不推荐股票或买卖时机，不诱导交易。
- 真实 Kimi／真实行情仍未授权；所有结果显著标 synthetic contract test。
- CN A 股是 P0 执行范围，但原型只有 synthetic 股票；US/JP 是未开放愿景，ETF／基金／指数按原契约矩阵。
- 对话 → AST → 校验 → 权威回读 → expectedDigest 确认 → 完整 Run 的硬顺序不变。
- 不修改 S0/S1/S2 代码、golden 数据逻辑或既有内核语义。
