## 3. 新标识设计说明（ayi-logo.svg）

延续原青金时间轨迹语言、最小改动替换字形：

- **字形**：H 形双竖＋横杠 → **A 形双斜笔（`M43 89 L64 39 L85 89`）＋「一」横杠（`M51 68h26`）**，即「阿一 / A YI」的 A／一意象；横杠与斜笔同粗（8px）、圆头，克制成形。
- **沿用元素**：深海军蓝圆角底（`#1e2943→#0a0e1a`）、青金渐变描边（`#00d4ff→#00a8cc→#ffd700`）、43r 时间轨迹圆环、右上金色上升箭头、青（轨迹起点）／金（终点）双端点——与原 H 形标识同 footprint（高 50、跨 42），版式无位移。
- **协调**：渐变方向与金色箭头不动，与深海军蓝基底的明暗、冷暖关系维持原设计；双主题下不新增色值。
