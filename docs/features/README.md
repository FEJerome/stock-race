# Feature 文档

`docs/features/` 是任务执行正典，承载目标、范围、接口或文件变化、验收条件与实际验证记录。

## 写作规则

- 一个任务一份主文档，编号与任务名同时出现，例如 `SR-001-collaboration-base.md`。
- 先讨论并确认方案，再施工；施工中出现的范围变化须先记录并获授权。
- 实时任务状态归项目指定的 STATUS 底账，本目录不复制任务看板。
- 不复制整套协作手册或架构文档，只链接相关住所。
- 验证记录写明实际执行的检查、结果和未覆盖项，不把计划写成结果。
- 会话消息、提示词与交接草稿不是 feature 的替代品。
