# TODO.md 标准格式规范

**本文档**：定义模块 TODO.md 的标准格式，确保自动化开发系统能够统一解析任务状态。

---

## 文件结构

```markdown
# {模块名称} 模块 - 开发任务追踪

> 本文档仅记录未完成和待其他服务跟进的工作项。
> 已完成功能请查阅 [HAVE_DONE.md](./HAVE_DONE.md)。
> 测试脚本请查阅 [TEST_SCRIPTS.md](./TEST_SCRIPTS.md)。
> **最后更新：{YYYY-MM-DD}**

---

## 格式说明（自动化开发使用）

任务必须使用以下格式标记：
```markdown
<!-- AUTO-TASK: BEGIN {task-id} -->
### {task-id}: 任务标题
- **自动化任务**: {queue-task-id}      # 对应 queue.json 的任务ID
- **状态**: 🔲 待开发 / 🔄 开发中 / ✅ 已完成 / ⛔ 阻塞
- **优先级**: P0/P1/P2/P3
- **描述**: 任务详细描述
- **技术方案**: 实现步骤
- **验收标准**: 完成检查项
- **测试需求**: 测试要求
<!-- AUTO-TASK: END {task-id} -->
```

---

## 状态图例

- 🔴 **P0-紧急** - 阻塞性问题，必须立即解决
- 🟠 **P1-高** - 重要功能，优先处理
- 🟡 **P2-中** - 一般功能，按计划处理
- 🟢 **P3-低** - 优化项，有空时处理
- 🔲 待开发
- 🔄 开发中
- ⚠️ 待验证/部分完成
- ⏸️ 阻塞（依赖其他服务）
- ✅ 已完成（已移至 HAVE_DONE.md）
