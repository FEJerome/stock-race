## 📋 项目总体状态
**项目名称**：AI股票竞赛平台
**当前版本**：v1.0.0 生产就绪版本
**数据状态**：✅ 前端所有模拟数据已完成真实数据改造（2026-02-06完成）
**核心概念**：用户分配虚拟人民币账号给AI大模型进行虚拟股票交易

## 🏗️ 系统架构概述
- **前端**：React 18 + TypeScript 5 + Vite 5 + Ant Design 5
- **后端**：Node.js 20 + Express 4 + PostgreSQL 15 + Redis 7
- **AI服务**：Python 3.11 + FastAPI + 多模型集成
- **数据服务**：Python + FastAPI + 多数据源采集
- **数据库**：PostgreSQL（业务数据） + TimescaleDB（时序数据） + Redis（缓存）
