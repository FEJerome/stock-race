### 市场服务缓存集成模式
```typescript
getStockQuotes: async (symbols?: string[]): Promise<Stock[]> => {
  // 1. 生成缓存键
  const cacheKey = symbols ? `stocks_quotes_${symbols.sort().join('_')}` : 'stocks_quotes_default';
  
  // 2. 尝试从缓存获取（考虑市场时间）
  const cached = cacheManager.getWithMarketTime(cacheKey, true);
  if (cached) return cached;
  
  // 3. 调用真实API
  const response = await api.post<Stock[]>('/stocks/realtime/batch', ...);
  
  // 4. 转换数据格式并缓存
  const stocks = response.map(stock => ({ ... }));
  const ttl = cacheManager.isTradingTime() ? 300000 : 1800000;
  cacheManager.set(cacheKey, stocks, ttl);
  
  return stocks;
}
```

## 📊 缓存性能优化

### 缓存命中策略
1. **首次请求**：调用API，缓存结果
2. **重复请求**（5分钟内）：使用缓存
3. **非交易时间**：延长缓存时间至30分钟
4. **API失败**：使用缓存或降级数据

### 内存使用优化
- 内存缓存：Map对象，自动清理过期数据
- 本地存储：带前缀隔离，JSON序列化
- 定期清理：自动清理过期缓存
