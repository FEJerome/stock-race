## 🔧 发现的问题与修复建议

### 高优先级问题
1. **市场指数API缺失函数**
   - 问题: `marketController.getIndices is not a function`
   - 影响: /api/market/indices 端点不可用
   - 建议: 在MarketController中添加getIndices函数或移除该路由

2. **AI服务缓存不可用**
   - 问题: Redis连接配置问题导致缓存不可用
   - 影响: AI服务显示"degraded"状态
   - 建议: 修复Redis连接配置，使用正确的连接字符串

### 中优先级问题
1. **部分API端点缺失**
   - 问题: /api/ai/accounts 端点不存在
   - 影响: AI账户管理功能不完整
   - 建议: 实现相关端点或更新前端调用

2. **数据服务端点路径不一致**
   - 问题: 数据服务需要/api/v1前缀，但文档可能未明确说明
   - 影响: 直接调用可能失败
   - 建议: 统一API路径规范或更新文档

### 低优先级问题
1. **OpenAI API依赖**
   - 问题: 测试环境缺少真实的AI API密钥
   - 影响: AI决策返回超时错误
   - 建议: 生产环境配置真实API密钥，测试环境使用模拟模式
