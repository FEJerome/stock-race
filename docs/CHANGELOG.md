### [v1.0-draft.6] - 2026-03-11

#### 新增（合规设计）
- [4.2.2] 策略收集力度分级：细/中/粗三级合规策略，防止 AI 擅自荐股
  - 细力度：提供具体股票代码 → AI 直接执行
  - 中力度：提供板块/行业 → AI 提供 2-3 选项，需用户确认
  - 粗力度：仅概念性描述 → 拒绝直接选股，引导明确标的
- [4.2.2] 前端体现方式：A+C 结合方案（AI 对话引导 + UI 提示标志）

#### Local 前端实施
- 主题切换功能：跟随系统/深色/浅色三模式，检测失败默认深色
- 沙盒水印：固定右下角显示"虚拟沙盒环境 · 数据仅供演示"
- 产品说明弹窗：首次访问自动显示，含核心概念和免责声明

#### 决策记录
- 5.1 策略力度前端体现：确认 A+C 结合方案（对话引导 + UI 提示）
- 5.2 主题切换默认设置：确认跟随系统，检测失败默认深色
