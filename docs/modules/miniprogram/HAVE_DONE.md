### Phase 6: 游客模式（T-011）

| 编号 | 功能模块 | 完成状态 | 关键文件 | 代码质量 |
|------|---------|---------|---------|---------|
| T-011 | 游客模式功能 | ✅ | `stores/auth.ts`, `pages/login/login.vue` | 优秀 |

**T-011 游客模式特性：**

**1. 游客状态管理** (`stores/auth.ts`)
- `isGuestMode` - 计算属性判断是否为游客
- `isLoggedIn` - 排除游客token的真正登录判断
- `enableGuestMode()` - 启用游客模式
- `requireAuth(redirectUrl)` - 需要登录时跳转
- `wechatLogin(code)` - 微信登录

**2. 首页改造** (`pages/index/index.vue`)
- 移除 `onMounted` 中的强制登录检查
- 无token时自动启用游客模式
- 游客可访问公开数据（排行榜、行情）

**3. 登录页改造** (`pages/login/login.vue`)
- 大号微信登录按钮（绿色醒目）
- 演示账户登录（折叠式）
- "暂不登录，继续浏览"入口
- 登录成功后支持redirect跳转

**4. API权限控制**
- 公开API：排行榜、行情（无需token）
- 私有API：AI账户、持仓、交易记录（需登录）
- 游客访问私有API时跳转登录页

### 2.2 数据流设计

**1. 登录流程**
```
用户访问首页
    │
    ├─ 无token ──> 启用游客模式 ──> 显示首页（游客UI）
    │
    └─ 有token ──> 验证token ──> 显示首页（完整UI）
         │
         └─ token过期 ──> 跳转登录页
```

**2. 游客访问受限功能**
```
用户点击"创建AI经理"
    │
    ├─ 游客模式 ──> requireAuth()检查 ──> 跳转登录页
    │                                    (携带redirect参数)
    │
    └─ 已登录 ──> 正常跳转创建页
```

**3. 缓存策略**
| 数据类型 | 缓存时长（交易时间） | 缓存时长（非交易时间） | 存储位置 |
|---------|-------------------|---------------------|---------|
| 行情数据 | 30秒 | 1小时 | 内存/Storage |
| 用户信息 | 15分钟 | 30分钟 | Pinia持久化 |
| 持仓数据 | 5分钟 | 10分钟 | 内存 |
| AI账户 | 5分钟 | 10分钟 | 内存 |
| 排行榜 | 5分钟 | 30分钟 | 内存 |
