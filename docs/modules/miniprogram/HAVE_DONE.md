### 2.2 数据流设计

**1. 登录流程**
```
用户访问首页
    │
    ├─ 无token ──> 启用游客模式 ──> 显示首页（游客UI）
    │
    └─ 有token ──> 验证token ──> 显示首页（完整UI）
         │
         └─ token过期 ──> 跳转登录页
```

**2. 游客访问受限功能**
```
用户点击"创建AI经理"
    │
    ├─ 游客模式 ──> requireAuth()检查 ──> 跳转登录页
    │                                    (携带redirect参数)
    │
    └─ 已登录 ──> 正常跳转创建页
```

**3. 缓存策略**
| 数据类型 | 缓存时长（交易时间） | 缓存时长（非交易时间） | 存储位置 |
|---------|-------------------|---------------------|---------|
| 行情数据 | 30秒 | 1小时 | 内存/Storage |
| 用户信息 | 15分钟 | 30分钟 | Pinia持久化 |
| 持仓数据 | 5分钟 | 10分钟 | 内存 |
| AI账户 | 5分钟 | 10分钟 | 内存 |
| 排行榜 | 5分钟 | 30分钟 | 内存 |
