## 1. 策略收集 Prompt

### 1.1 系统角色

```
你是AI股票交易助手，正在帮助用户创建一位AI交易员。你需要通过对话收集用户的投资策略偏好，最终生成一份策略文档。

原则：
1. 每次只问一个问题，等待用户回答
2. 如果用户回答不清晰，温和地追问
3. 提供选项让用户选择，降低决策成本
4. 最终生成的策略文档要简洁明了
```

### 1.2 五维度收集流程

#### 维度1：风险承受

**Prompt**：
```
首先，请告诉我您对投资风险的承受能力。

选项：
A. 保守型 - 宁愿收益低，也不能接受本金大幅波动
B. 稳健型 - 可以接受小幅波动，追求稳定收益
C. 激进型 - 能承受较大波动，追求较高收益
D. 极度激进 - 能承受大幅回撤，追求最大收益

请选择 A/B/C/D，或用自己的话描述。
```

**追问逻辑**（用户选择不清晰时）：
```
如果市场突然下跌20%，您会：
- 立即卖出止损
- 继续持有等待反弹
- 加仓摊低成本

您的选择会帮助我理解您的风险承受度。
```

#### 维度2：关注板块

**Prompt**：
```
好的，接下来请告诉我您希望AI交易员关注哪些板块？

热门板块选项（可多选）：
□ 科技（AI、芯片、软件）
□ 消费（食品饮料、家电、零售）
□ 医药（创新药、医疗器械）
□ 新能源（光伏、电动车、储能）
□ 金融（银行、保险、券商）
□ 周期（有色、化工、煤炭）
□ 全市场 - 不限定板块

请直接回复选项编号，如"1,2,3"，或告诉我具体板块名称。
```

**追问逻辑**：
```
您选择了科技板块，能具体说明一下吗？

A. 全科技板块都关注
B. 主要关注AI相关
C. 主要关注芯片半导体
D. 主要关注软件服务

或者您可以描述具体关注的细分领域。
```

#### 维度3：持仓周期

**Prompt**：
```
了解。现在请告诉我您希望的持仓周期是？

选项：
A. 超短线 - 1-3天（高频交易，追求短期波动）
B. 短线 - 1-2周（捕捉短期趋势）
C. 中线 - 1-3个月（中期趋势投资）
D. 长线 - 半年以上（价值投资，忽略短期波动）

请选择最符合您偏好的选项。
```

**追问逻辑**：
```
您选择了中线（1-3个月）。请问：

如果持仓一个月后股票下跌10%，但基本面没有变化，您会：
- 立即卖出
- 继续持有到预定周期
- 加仓降低成本

这有助于我制定更精准的持仓策略。
```

#### 维度4：仓位与止损

**Prompt**：
```
现在设置仓位和止损规则。

单只股票仓位上限（占总资金比例）：
A. 10% - 极度分散
B. 20% - 较为分散
C. 30% - 适度集中
D. 50% - 较为集中
E. 不设上限 - 单押

止损纪律：
当股价下跌达到多少时，坚决止损？
A. 5% - 严格止损
B. 8% - 标准止损
C. 10% - 宽松止损
D. 15% - 极宽松
E. 不止损 - 死扛

请分别回复两个选项，如"C,B"。
```

**追问逻辑**：
```
您设置了30%单股上限和8%止损。

情景问题：如果一只股票已经盈利20%，您会：
- 止盈卖出
- 继续持有，按止损规则执行
- 加仓（让利润奔跑）

这会影响我的止盈策略制定。
```

#### 维度5：交易市场范围

**Prompt**：
```
最后一个问题：交易市场范围。

您希望AI交易员交易哪些市场？

A. 仅主板（沪A+深A主板，风险相对较低）
B. 主板+创业板（增加成长性股票）
C. 全市场（主板+创业板+科创板+北交所）

请选择您的偏好。
```

**追问逻辑**：
```
您选择了主板+创业板。

补充问题：对于创业板股票（涨跌幅±20%），您希望：
- 正常配置（与普通股票一样）
- 降低仓位（比普通股票仓位减半）
- 谨慎参与（仅在确定性高时买入）

请告诉我您的偏好。
```

## 2. AI 决策 Prompt

### 2.1 系统角色 Prompt

```
你是一位专业的AI股票交易员，严格遵循以下原则：

1. 专业素养：
   - 基于数据和事实进行分析，不情绪化
   - 严格遵守投资策略约束（风险承受、仓位控制、止损纪律）
   - 在策略框架内寻求最优解

2. 风险控制：
   - 绝不超出单股仓位上限
   - 严格执行止损纪律
   - 只在指定交易范围内操作
   - 根据风险承受度控制总体仓位

3. 决策风格：
   - 稳健型：优先保住本金，宁可错过也不做错
   - 激进型：追求收益，但严格遵守风控规则
   - 极度激进：敢于博弈，但必须有明确止损

4. 输出要求：
   - 给出明确的行动建议（买入/卖出/持有/观望）
   - 说明决策理由（数据支撑）
   - 评估风险等级
   - 建议仓位占比
```

## 3. Prompt 优化指南

### 3.1 提升决策质量的方法

1. **上下文丰富度**
   - 提供更多历史数据（过去5日K线）
   - 加入技术指标（MA5/MA10/MA20）
   - 加入资金流向数据

2. **约束明确化**
   - 明确仓位上限数字
   - 明确止损价格
   - 明确可交易股票列表

3. **少样本学习（Few-shot）**
   ```
   以下是几个决策示例供参考：

   示例1（买入）：
   场景：低估值+技术突破
   决策：买入，仓位5%
   理由：...

   示例2（卖出）：
   场景：触及止损
   决策：卖出全部
   理由：...
   ```

### 3.2 减少幻觉的策略

1. **数据限定**
   - 明确告知AI只能基于提供的数据决策
   - 禁止AI编造数据

2. **置信度校准**
   - 要求AI给出0-1的置信度
   - 置信度<0.6时建议观望

3. **一致性检查**
   - 决策必须与策略约束一致
   - 超约束的决策会被系统拒绝

## 4. Token 控制策略

### 4.1 各模型 Token 限制

| 模型 | 上下文长度 | 推荐输入限制 | 推荐输出限制 |
|------|-----------|-------------|-------------|
| DeepSeek-Chat | 64K | 4000 tokens | 1000 tokens |
| 通义千问-Turbo | 8K | 3500 tokens | 1000 tokens |
| Kimi | 200K | 4000 tokens | 1000 tokens |
| GLM-4 | 128K | 4000 tokens | 1000 tokens |

### 4.2 Token 优化策略

**输入优化**：
1. 持仓只保留前5只股票
2. 行情只保留关键字段（价格、涨跌幅、成交量）
3. 历史决策只保留最近3次
4. 移除冗余的市场情绪描述

**输出优化**：
1. 要求JSON格式输出（结构化，token效率高）
2. reason字段限制100字
3. analysis字段可选（减少token消耗）

**Token 估算公式**：
```python
tokens = (
    system_prompt_tokens +      # ~500
    strategy_tokens +           # ~300
    portfolio_tokens +          # ~200 * min(position_count, 5)
    market_tokens +             # ~100 * min(watchlist_count, 10)
    history_tokens +            # ~150 * min(history_count, 3)
    context_tokens +            # ~100
    output_tokens               # ~500
)
```

**截断优先级**（当超出限制时）：
1. 截断历史决策（3次→2次→1次→0次）
2. 精简市场概况描述
3. 减少观察列表股票数量
4. 精简策略描述（保留关键约束）

## 5. 测试与调优

### 5.1 Prompt 测试用例

**测试场景1：止损触发**
```
持仓：某股票跌幅8%
策略：8%止损
预期：AI应建议卖出
```

**测试场景2：超仓位限制**
```
持仓：某股票已达30%仓位上限
策略：单股不超过30%
预期：AI不能建议继续买入该股票
```

**测试场景3：板块限制**
```
策略：只关注科技板块
行情：消费板块股票大涨
预期：AI不应建议买入消费板块股票
```

### 5.2 调优迭代流程

1. **收集反馈**
   - 记录AI决策与人工判断的差异
   - 收集用户对"内心戏"的反馈

2. **分析模式**
   - 识别AI的系统性偏差
   - 找出约束理解不清的情况

3. **优化 Prompt**
   - 强化约束描述
   - 增加示例
   - 调整语气和风格

4. **A/B 测试**
   - 对比不同版本的决策质量
   - 选择最优Prompt
