## 二、架构实现详情

### 2.1 多数据源架构

```
┌─────────────────────────────────────────────────────────────┐
│                    DataSourceRouter                         │
├──────────┬──────────┬──────────┬──────────┬─────────────────┤
│  新浪    │  腾讯    │ 东方财富 │ AkShare  │ Baostock/Tushare│
│ Sina     │ Tencent  │ EastMoney│ (实时)   │ (历史数据)      │
│ (主)     │ (备)     │ (备)     │          │                 │
└──────────┴──────────┴──────────┴──────────┴─────────────────┘
                    ↓
         ┌──────────────────────┐
         │   数据质量评估引擎    │
         │  - 多源比对           │
         │  - 异常检测           │
         │  - 降级策略           │
         └──────────────────────┘
```

**实现亮点：**
- 6个数据源动态权重管理
- 自动故障检测与切换（10次连续错误后停用）
- 5分钟后自动恢复机制
- 数据源健康评分（0-100分）

### 2.2 分层采集策略

| 层级 | 采集频率 | 覆盖范围 | 数据源 |
|------|---------|---------|--------|
| 高频层 | 10秒 | 热股票（持仓+关注，约300只） | 新浪财经 |
| 中频层 | 60秒 | 全市场其他股票 | 多源并行 |
| 低频层 | 日终 | 历史K线数据 | Baostock/Tushare |

### 2.3 三层缓存架构

```
Layer 1: Redis 热缓存 (TTL: 10秒)
    - 实时行情数据
    - 股票基本信息
    - 市场状态

Layer 2: TimescaleDB 时序数据库
    - 历史行情数据
    - 技术指标计算结果
    - 数据质量指标

Layer 3: 内存回退缓存 (Redis故障时)
    - 自动降级机制
    - 保证服务可用性
```

### 2.4 事件总线集成架构

```
┌─────────────────────────────────────────────────────────────┐
│                 Market Data Service                         │
│  ┌─────────────────────────────────────────────────────┐    │
│  │         MarketDataEventPublisher                    │    │
│  │  ┌─────────────┐ ┌─────────────┐ ┌─────────────┐   │    │
│  │  │ publish_    │ │ check_and_  │ │ publish_    │   │    │
│  │  │ quote()     │ │ publish_    │ │ indicator_  │   │    │
│  │  │             │ │ price_alert()│ │ update()    │   │    │
│  │  └──────┬──────┘ └──────┬──────┘ └──────┬──────┘   │    │
│  │         └───────────────┼───────────────┘          │    │
│  │                         ↓                          │    │
│  │              ┌─────────────────────┐               │    │
│  │              │   Redis Streams     │               │    │
│  │              │  (event-bus)        │               │    │
│  │              └─────────────────────┘               │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
                              │
          ┌───────────────────┼───────────────────┐
          ↓                   ↓                   ↓
   ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
   │   Backend   │    │ AI Service  │    │News Service │
   │  (WebSocket)│    │ (决策订阅)  │    │ (异动订阅)  │
   └─────────────┘    └─────────────┘    └─────────────┘
```

**实现亮点：**
- 统一事件总线解耦：Backend/AI Service/News Service 无需直接调用 Market Data
- 三种事件类型：实时行情(market:quote:realtime)、价格异动(market:alert:price_move)、技术指标(market:indicator:updated)
- 涨跌幅>7%自动触发异动事件，支持News Service实时新闻联动
- 每10秒批量发布行情事件，降低Redis负载

### 2.5 广度查询架构（板块/行业/指数）

```
┌─────────────────────────────────────────────────────────────┐
│                   Data Service API                          │
├──────────────┬──────────────┬───────────────────────────────┤
│  /sector/    │  /industry/  │  /index/                      │
│  {sector}    │  {industry}  │  {index}/components           │
│  /quotes     │  /quotes     │                               │
└──────────────┴──────────────┴───────────────────────────────┘
              ↓              ↓                ↓
    ┌─────────────────────────────────────────────────────┐
    │              Stock Classification                   │
    │  ┌──────────┐ ┌──────────┐ ┌──────────┐            │
    │  │  Sector  │ │ Industry │ │ Concept  │            │
    │  │  板块    │ │  行业    │ │  概念    │            │
    │  │(financial│ │(banking/ │ │(5G/AI/  │            │
    │  │technology│ │software) │ │EV)      │            │
    │  └──────────┘ └──────────┘ └──────────┘            │
    └─────────────────────────────────────────────────────┘
                           ↓
              ┌──────────────────────┐
              │   Redis Cache (5min) │
              │   Pagination Support │
              └──────────────────────┘
```

**实现亮点：**
- 支持多维度股票分类：板块(financial/technology/healthcare等)、行业(banking/software/energy等)、概念标签
- 智能排序：支持按市值(market_cap)、价格(price)、涨跌幅(change_percent)、成交量(volume)排序
- 分页优化：支持skip/limit分页，大数据量查询性能优异
- Redis缓存：5分钟TTL，减少重复计算

### 2.6 公开WebSocket架构

```
┌─────────────────────────────────────────────────────────────┐
│              PublicWebSocketManager                         │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  Connection Management (No JWT Required)            │    │
│  │  ┌─────────────┐ ┌─────────────┐ ┌─────────────┐   │    │
│  │  │  connect()  │ │ subscribe() │ │unsubscribe()│   │    │
│  │  │             │ │  (max 50)   │ │             │   │    │
│  │  └─────────────┘ └─────────────┘ └─────────────┘   │    │
│  │                         ↓                          │    │
│  │              ┌─────────────────────┐               │    │
│  │              │  Broadcast Loop     │               │    │
│  │              │  (every 10s)        │               │    │
│  │              └─────────────────────┘               │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
                              │
                              ↓
                   ┌─────────────────────┐
                   │   Miniprogram       │
                   │   (Public Access)   │
                   └─────────────────────┘
```

**实现亮点：**
- 无需JWT认证：公开WebSocket端点，支持游客模式访问
- 订阅限流：单个连接最多订阅50只股票，防止资源滥用
- 批量订阅：支持一次性订阅多只股票
- 自动广播：每10秒推送订阅列表的最新行情
