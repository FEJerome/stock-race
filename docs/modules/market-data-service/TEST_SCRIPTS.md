
### Phase 7: 动态高频层采集（已完成）

**开发模式**: 测试驱动开发（TDD）

**核心功能**:
1. DynamicHighFreqScheduler: 根据系统健康状态动态调整高频层股票数量
   - 4源健康: 200只, 10秒间隔
   - 3源健康: 150只, 10秒间隔
   - 2源健康: 100只, 10秒间隔
   - 1源健康: 50只, 15秒间隔
   - 0源健康: 0只, 暂停高频层

2. HotStockSelector: 加权热股票选取器
   - 按权重排序选取前N只股票
   - 处理缺失/异常权重
   - 权重计算因子: 查看用户数(40%) + 查看次数(30%) + 交易活跃度(20%) + 收藏数(10%)

**测试成果**:
- test_dynamic_high_freq_scheduler.py: 30个测试用例全部通过
- 覆盖功能: 动态股票数量计算、健康状态映射、权重排序选取、边界条件处理
