# 多形态交付策略

本文档定义 AI股票竞赛平台 三种产品形态的交付边界。

- **Local**：纯工具，单机验证技术可行性
- **MVP**：合规验证版，微信小程序7天试用
- **Full**：完整商业版，全功能开放

## 分层交付策略

### 核心层（三种形态共用）

这些逻辑写一次，三种形态共用：

| 组件 | 位置 | 说明 |
|------|------|------|
| AI交易员状态机 | `core/state-machine/` | 生命周期管理 |
| Prompt模板 | `core/prompts/` | 策略收集+交易决策 |
| 交易计算逻辑 | `core/trading-engine/` | 虚拟交易、收益计算 |
| 数据模型 | `core/models/` | 共用数据定义 |

### 适配层（形态差异）

| 组件 | Local | MVP | Full |
|------|-------|-----|------|
| **存储** | SQLite本地文件 | PostgreSQL云服务 | PostgreSQL+Redis集群 |
| **数据源** | 本地CSV历史数据 | 新浪财经API | 多源实时行情 |
| **用户认证** | 无（本地单用户） | 微信OpenID | 完整账号体系 |
| **前端** | CLI命令行 | 微信小程序 | 小程序+Web+App |
| **支付** | 无 | 无（7天试用） | 微信支付订阅 |

## 详细功能边界

### 1. AI交易员创建

**Local**：
- 通过配置文件或CLI参数创建
- 无UI，纯命令行
- 策略通过JSON文件预定义

**MVP**：
- 小程序内表单创建
- 策略收集对话（标准5维度）
- 仅支持DeepSeek单一模型

**Full**：
- 多模型选择（DeepSeek/通义/Kimi等）
- AI人设选择
- 高级策略配置

### 2. 交易执行

**Local**：
- 读取本地CSV历史数据
- 模拟交易执行
- 结果输出到本地文件

**MVP**：
- 接入新浪财经实时API
- 真实A股交易时间执行
- 7天试用期后锁定

**Full**：
- 多数据源（东方财富、同花顺等）
-  failover自动切换
- 实时推送+历史回测

### 3. 用户系统

**Local**：
- 无用户概念
- 数据存储在本地SQLite
- 单机使用

**MVP**：
- 微信小程序授权登录
- 获取OpenID识别用户
- 7天试用倒计时

**Full**：
- 完整注册/登录/找回密码
- 实名认证
- 订阅状态管理

## 开发顺序建议

**Phase 1：Local 核心验证**
1. 交易引擎（本地CSV数据）
2. AI策略收集（CLI交互）
3. 虚拟交易执行
4. 收益计算

**Phase 2：MVP 合规验证**
1. 接入实时行情API
2. 微信小程序登录
3. 7天试用限制
4. 简化版排行榜

**Phase 3：Full 商业运营**
1. 等级系统
2. 订阅支付
3. 多模型支持
4. 完整社交功能
