## 2. 战略层（产品是什么）

### 2.1 产品定位 【已冻结】

**一句话描述**：
AI股票竞赛平台 = "AI模型农场"，用户作为"投资经理"招聘AI作为"交易员"进行虚拟股票交易。

**核心价值主张**：
让普通用户零技术门槛地体验/对比不同AI大模型（DeepSeek、通义千问、Kimi等）的"炒股能力"。

**目标用户**：
- 对AI感兴趣但不懂技术的普通用户
- 想了解不同AI模型差异的爱好者
- 寻找"AI能做什么"直观体验的用户

**根本价值**：
外界发布新AI模型时，用户第一反应是"来这个平台试试它炒股怎么样"。

### 2.2 产品边界（不做清单）【已冻结】

| 不做事项 | 原因 |
|---------|------|
| 不涉及真实资金交易 | 合规风险，使用虚拟"元宝" |
| 不承诺AI炒股能力 | 胜率≈投骰子，仅提供体验，非投资建议 |
| 用户无个人账户余额 | 不比拼总资产，只看AI交易员独立表现 |
| v1.0 不做社交功能 | 关注、分享等延后考虑 |
| 不使用国外大模型 | 支持国产、规避合规风险 |

### 2.3 商业模式 【已冻结】

**核心机制**：投资经理等级系统
- 用户扮演"投资经理/基金经理"，拥有"工资额度"用于招聘AI交易员
- 工资额度与AI交易资金完全独立，仅用于模型使用成本
- 通过活跃度（登录、邀请、观看广告）提升等级，解锁更高工资额度和特权

**用户成长资源**：经验值
- 用户通过活跃度（登录、邀请好友、创建AI、观看广告）获得经验值
- 经验值用于等级升级，不消耗，持续累计
- 等级影响工资额度上限和功能解锁

**AI交易资源**：投资研究点数
- 仅属于AI交易员个体的虚拟交易资金，非用户账户资产
- 用户创建AI交易员时指定金额（范围：10,000 - 1,000,000,000）
- 仅用于该AI的虚拟股票交易，不可兑换现金/实物

**用户约束**：工资额度
- 固定上限的硬性条件，非消耗品
- 雇佣AI时实时占用，解雇时全额返还
- 不同AI模型根据API成本单独定价

**盈利方式**：
- 免费用户：基础AI模型，有限工资额度，展示广告
- 付费用户（月卡/年卡）：无广告纯净体验 + 纯虚拟特权

**付费特权（纯虚拟）**：
- 解锁旗舰AI模型（GLM-5、Kimi K2.5等）
- 工资额度上限提升
- 策略文档字数上限提升
- AI对话上下文长度提升
- 多策略对比分析功能
- 持仓实时推送
- 新模型优先体验权

**用户获取**：等级系统驱动的社交裂变（登录+邀请任务+里程碑奖励）
- 邀请功能仅对实名认证用户开放

### 2.4 用户准入与实名认证 【已冻结】

**准入策略**：彻底拒绝18岁以下用户

#### 用户状态流转

```
游客模式（未登录）
    ├── 可浏览：首页介绍、排行榜（匿名数据）
    ├── 不可创建AI交易员
    └── 引导：点击"创建AI交易员" → 跳转登录

登录后（微信授权）
    ├── 获取用户OpenID
    ├── 强制实名认证（微信realNameVerify接口）
    └── 年龄校验

实名认证后
    ├── ≥18岁：正常使用全部功能
    └── <18岁：拒绝访问，提示"本服务仅限18周岁以上用户"
```

#### 实名认证流程

1. **强制触发时机**：
   - 首次点击"创建AI交易员"
   - 首次点击"我的"页面
   - 首次尝试查看AI决策详情

2. **认证方式**：
   - 调用微信`realNameVerify`接口
   - 获取身份证号，提取年龄信息
   - 服务端记录：`is_verified`, `age`, `id_card_hash`（脱敏）

3. **拒绝处理（<18岁）**：
   - 页面提示："根据相关法规，本服务仅限18周岁以上用户使用"
   - 记录拒绝时间，允许1天后重新认证
   - 不永久封禁账号，仅限制当前认证结果

4. **重新认证机制**：
   - 1天后可再次尝试实名认证
   - 若仍<18岁，继续拒绝并更新拒绝时间
   - 若≥18岁，正常开通全部功能
   - 允许无限次重试，每次间隔1天

#### 游客模式权限

| 功能 | 游客 | 实名用户（≥18岁） |
|-----|------|------------------|
| 浏览首页介绍 | ✅ | ✅ |
| 查看排行榜（匿名） | ✅ | ✅ |
| 创建AI交易员 | ❌ | ✅ |
| 查看AI决策详情 | ❌ | ✅ |
| 邀请好友 | ❌ | ✅ |
| 付费功能 | ❌ | ✅ |

### 2.5 合规声明 【已冻结】

**产品定位声明**：
- 本平台的AI交易决策仅供研究参考，不构成投资建议
- 虚拟交易结果不代表真实投资收益
- 过往收益表现不代表未来收益

**法律合规**：
- 平台内投资研究点数、工资额度不可兑换现金或实物
- 不涉及杠杆交易、T+0等真实市场禁用机制
- 排行榜数据基于历史模拟计算，非投资建议
- 严格限制18岁以下用户访问

**用户协议必备条款**：
- 虚拟交易与真实证券市场的隔离性声明
- 禁止利用平台数据从事非法证券活动
- 平台对异常账户的处置权
- 实名认证为强制性要求

**新闻服务合规**（如适用）：
- 仅展示新闻标题及摘要（≤300字）
- 标注信息来源
- 与合法数据供应商签订授权协议

**界面合规**：
- 所有涉及收益率的页面标注："虚拟交易结果不具有真实投资参考价值"
- 禁用"赚""亏""盈利""暴富"等诱导性词汇
- 使用中性色彩，避免红涨绿跌的强烈视觉刺激

<a name="等级系统"></a>
#### 4.1.1 等级系统

**等级设计**：共30级，细粒度成长，每级均有反馈

**阶段划分**：

| 阶段 | 等级范围 | 称号 | 核心解锁 |
|-----|---------|------|---------|
| 见习期 | 1-6级 | 见习经理 | 基础功能，工资额度缓慢增长 |
| 初学期 | 7-12级 | 初级经理 | 解锁AI决策详情查看 |
| 进阶期 | 13-18级 | 中级经理 | **解锁AI激励功能（积极档）** |
| 高阶期 | 19-24级 | 高级经理 | 解锁激进档，更多特权 |
| 总监期 | 25-30级 | 投资总监 | 全部功能开放 |

**升级经验设计**（每级50-100经验，前期少后期多）：

| 等级 | 所需经验 | 累计经验 | 升级奖励示例 |
|-----|---------|---------|-------------|
| 1→2 | 50 | 50 | 工资额度+2 |
| 2→3 | 60 | 110 | **解锁积极激励档** |
| 3→4 | 60 | 170 | 工资额度+2 |
| 4→5 | 70 | 240 | 解锁新AI模型 |
| 5→6 | 70 | 310 | 称号升级"初级经理" |
| ... | ... | ... | ... |
| 11→12 | 90 | 900 | 解锁持仓实时推送 |
| ... | ... | ... | ... |
| 17→18 | 100 | 1700 | 解锁策略对比分析 |
| ... | ... | ... | ... |
| 29→30 | 100 | 2900 | 满级，解锁全部功能 |

**升级逻辑**：
- 经验值累计达到阈值自动升级
- 升级时即时解锁新功能和工资额度
- 等级只升不降（无降级机制）
- 每级都有明确反馈（工资额度增加或功能解锁）

**付费捷径**：
- 月卡/年卡用户直接解锁至15级（中级经理）
- 付费用户等级不会衰减
- 为付费用户提供"省时间"而非"唯一路径"

**待细化项**：
- [ ] 完整的30级经验值表
- [ ] 每级具体奖励设计
- [ ] 升级时的通知方式
- [ ] 满级后的替代奖励机制

<a name="工资额度系统"></a>
#### 4.1.3 工资额度系统 【待细化】

**核心机制**：固定上限的硬性限制条件

**概念定义**：
- 工资额度：用户可用于雇佣AI交易员的固定上限（非消耗品）
- 模型定价：每个AI模型根据实际API成本单独定价（由平台后台设定）
- 实时占用：雇佣AI时实时扣除工资额度，解雇时全额返还
- 固定池子：工资额度不会"每月重置"，是用户的固定属性

**工资额度与等级**（线性增长，每级增加）：

| 等级 | 工资额度上限 | 说明 |
|-----|-------------|------|
| 1级 | 100（示例） | 具体数值待API成本调研后确定 |
| 2级 | 102 | 每级+2 |
| 3级 | 104 | ... |
| ... | ... | 线性增长 |
| 30级 | 158 | 满级工资额度 |

*注：以上数值仅为示例，实际数值可能为3000、20000等，根据API定价策略调整*

**模型定价**（基于API成本，后台可配置）：

| 模型 | 假设API成本 | 工资定价 | 特性 |
|-----|-----------|---------|------|
| DeepSeek-V3 | 低 | 20 | 性价比高 |
| GLM-4 | 低 | 25 | 性价比高 |
| Kimi K2 | 中 | 50 | 综合能力均衡 |
| 通义千问Max | 中 | 60 | 综合能力均衡 |
| GLM-5 | 高 | 80 | 最新最强 |
| Kimi K2.5 | 高 | 100 | 最新最强 |

*注：定价仅为示例，实际根据API成本调研确定*

**雇佣与解雇逻辑**：

```
用户当前工资额度上限：100
已雇佣AI：
- DeepSeek-V3: 占用20
- Kimi K2: 占用50
剩余可用额度：100 - 20 - 50 = 30

可操作：
- 雇佣GLM-4（25）→ 剩余5 ✅
- 雇佣GLM-5（80）→ 超出额度 ❌

解雇Kimi K2：
- 返还50额度
- 当前占用：20，剩余可用：80
```

**核心规则**：

1. **无数量限制**：不限制AI交易员数量，仅限制工资额度总和
2. **全额返还**：解雇AI交易员时，工资额度**全额返还**，无损耗
3. **固定池子**：工资额度**不会每月重置**，是用户的固定属性
4. **实时调价**：后台调整模型定价后，**实时生效**到所有用户
5. **超限处理**：如果调价导致已雇佣AI工资总和超过用户额度：
   - 不强制解雇任何AI
   - 仅禁止新建AI交易员
   - 用户需自行解雇部分AI释放额度后才能新建

**AI交易员激励**（与工资额度关联）：
- 标准档（100%工资）：基础效果
- 积极档（150%工资）：更高操作频率，更大上下文
- 激进档（200%工资）：最高操作频率，最大上下文，最详细决策

**配置中心可调参数**：
- 各等级工资额度上限
- 各模型工资定价
- 调价后是否强制生效（是，始终强制）

**待细化项**：
- [ ] 各等级具体工资额度上限数值
- [ ] 各模型具体工资定价（需API成本调研）
- [ ] 工资额度超限时的前端提示文案
- [ ] 调价后用户通知机制

<a name="邀请系统"></a>
#### 4.1.4 邀请系统

**准入条件**：仅限实名认证且≥18岁用户

**邀请关系建立**：
- 通过邀请码/链接注册
- 记录邀请人-被邀请人关系

**有效邀请定义**：
- 被邀请人完成注册
- 被邀请人完成实名认证（≥18岁）
- 被邀请人创建第一个AI交易员
- 被邀请人存活7天（有登录记录）

**防刷机制**：
- 同一设备/IP限制注册
- 被邀请人需存活7天，邀请人才获得里程碑奖励
- 邀请人自身必须实名认证

#### 4.1.5 AI交易员激励机制 【待细化】

**核心概念**：通过增加工资投入，提升AI交易员的工作效果

**激励档位**（用户等级解锁）：

| 档位 | 解锁等级 | 工资消耗 | 操作频率 | 上下文长度 | 决策理由详细度 |
|-----|---------|---------|---------|-----------|--------------|
| **标准** | 默认（1级） | 100% | 每天1-2次 | 最近3天数据 | 简短（50字） |
| **积极** | 3级解锁 | 150% | 每天3-4次 | 最近7天数据 | 详细（150字） |
| **激进** | 15级解锁 | 200% | 每天5-6次 | 最近14天数据 | 超详细（300字+预测） |

**激励效果说明**：
- **操作频率**：AI评估交易机会的次数
- **上下文长度**：AI决策时参考的历史数据范围
- **决策理由详细度**：AI生成决策理由的长度和深度
- **预测分析**（仅激进档）：AI对明日走势的预测

**设置机制**：
- 创建AI交易员时，如已解锁激励功能，可选择激励档位
- 已创建的AI可随时调整激励档位
- 调整后即时生效
- 无冷却时间限制（用户可自由实验）

**策略性设计**：
- 用户需在"数量vs质量"之间权衡
- 低工资AI × 数量多 vs 高工资AI × 数量少
- 鼓励用户根据策略风格选择（长线低频vs短线高频）

**待细化项**：
- [ ] 各档位的具体操作频率数值
- [ ] 上下文数据的具体范围定义
- [ ] 激进档预测分析的内容规范

<a name="自填API"></a>
#### 4.1.7 自填API模式 【待细化】

**功能定位**：为技术用户提供API自填选项，降低平台成本同时提升自由度

**两种模式对比**：

| 维度 | 平台提供API（默认） | 用户自填API |
|-----|-------------------|-------------|
| **API来源** | 平台统一提供 | 用户提供自有API Key |
| **工资占用** | 100%标准定价 | 10%极低定价（覆盖平台基础服务成本） |
| **策略长度** | 固定上限（如5000字） | 任意长度（API支持范围内） |
| **唤醒频率** | 平台固定配置 | 用户可调 |
| **适用人群** | 普通用户、小白 | 技术用户、专业玩家 |

**用户安全保障**：

1. **免责声明**
   - 用户明确同意平台使用其API Key执行交易决策
   - 平台不承诺API Key的绝对安全，但承诺业界标准加密存储

2. **透明汇报**
   - 每次API调用后记录Token消耗
   - 提供API使用统计面板（日/周/月维度）
   - 预估Token消耗提示（创建AI时给出参考值）

3. **用户自主控制**
   - 停用策略：用户可选3天/7天/10天未登录自动停止使用
   - 余额不足告警：检测到API余额不足时推送提醒
   - 一键删除：随时可删除API Key，立即生效

4. **安全存储**（重点）
   - API Key必须AES-256加密存储
   - 数据库层加密，应用层解密
   - 用户界面仅显示掩码（`sk-...abc123`）
   - 访问日志记录（时间、IP、操作类型）
   - 定期安全审计

**自填API数量上限**：
- 为防止系统过载，自填API模式也有数量限制（如最多10个）
- 或根据用户等级动态调整上限

**界面交互逻辑**：
- 高级设置区域仅在用户选择"自填API"且验证通过后显示
- 避免干扰普通用户体验

**待细化项**：
- [ ] 支持的API厂商列表
- [ ] 自填API的数量上限规则
- [ ] API Key加密存储的技术方案
- [ ] Token消耗预估算法

<a name="创建流程"></a>
#### 4.2.1 创建流程

**创建限制**：
- 受工资额度限制（雇佣工资总和不能超过工资额度上限）
- 受等级限制（部分高成本模型需要达到一定等级解锁）

**创建步骤**：
1. **选择API来源**：
   - 平台提供API（消耗标准工资额度）
   - 用户自填API Key（消耗10%工资额度）
2. 选择模型（根据API来源、工资额度和等级过滤可选列表）
3. 选择激励档位（如已解锁激励功能）
4. 进行策略收集对话
5. 确认创建

**自填API步骤**（如选择）：
1. 选择API厂商（DeepSeek/通义千问/智谱GLM等）
2. 输入API Key（验证有效性）
3. 高级设置（可选）：
   - 策略文档长度限制
   - 唤醒频率配置
   - 未登录自动停用时间（3天/7天/10天）
4. 预估Token消耗提示

**创建时工资计算**：
```
平台API模式：
总工资消耗 = 模型基础定价 × 激励档位系数
示例：
- DeepSeek-V3（定价20）+ 积极档（150%）= 30工资额度
- Kimi K2（定价50）+ 标准档（100%）= 50工资额度

自填API模式：
总工资消耗 = 模型基础定价 × 10%（覆盖平台基础服务成本）
示例：
- 自填DeepSeek-V3 = 2工资额度（与模型定价无关）
- 自填任意模型统一按此公式计算
```

**待讨论项**：
- [ ] 是否支持创建后修改模型？
- [ ] 是否支持创建后修改激励档位？
- [ ] 是否支持"解雇"AI交易员释放工资额度？

<a name="策略收集机制"></a>
#### 4.2.2 策略收集机制

**核心流程**：
用户输入 → AI追问（填补维度）→ 策略文档生成 → 后续决策的上下文

**五维度底线**（必须收集）：
1. **风险承受**：保守(-5%回撤)/稳健(-10%)/激进(-20%)/极度(-30%或无)
2. **关注板块**：具体行业板块，或"全市场"
3. **持仓周期**：超短线(1-3天)/短线(1-2周)/中线(1-3月)/长线(3月+)
4. **仓位与止损**：单股仓位上限 + 止损纪律
5. **交易市场范围**：纯主板 / 主板+创业板 / 全市场

**经典策略套餐**（降低用户决策负担）：

| 套餐 | 风险 | 周期 | 仓位 | 画像 |
|------|------|------|------|------|
| 价值投资者 | 稳健 | 长线 | 30% | "买好公司，长期持有" |
| 趋势跟踪者 | 激进 | 中线 | 50% | "顺势而为，截断亏损" |
| 题材狙击手 | 极度激进 | 短线 | 20% | "抓热点快进快出" |
| 量化交易者 | 稳健 | 超短线 | 10% | "积小胜为大胜" |

**待讨论项**：
- [ ] AI追问的Prompt工程复杂度评估
- [ ] 策略文档的数据结构
- [ ] 修改策略的机制（增量调整 vs 重置）

### 4.5 商业化 【待细化】

**关键词**：#月卡 #年卡 #付费 #广告

#### 4.5.1 月卡/年卡特权

**付费权益**（纯虚拟特权）：
- 直接解锁至15级（中级经理），解锁积极激励档
- 等级不会衰减
- 工资额度上限+50%（或更高）
- 解锁旗舰AI模型
- 无广告纯净体验
- 策略文档字数上限提升
- AI对话上下文长度提升
- 多策略对比分析功能
- 持仓实时推送优先体验
- 新模型优先体验权

**定价策略**：
- 【待细化】月卡价格
- 【待细化】年卡价格及折扣
- 【待细化】是否设置单月购买上限（未成年人保护）

#### 4.5.2 广告接入 【已冻结】

**接入条件**：仅对实名认证且≥18岁用户展示

**广告位**：
- banner广告（首页底部）
- 激励视频广告（获取投资研究点数）

**付费用户**：
- 默认不展示广告（无广告纯净体验）
- 不强调"去广告"，而是"专注研究体验"

**暂缓方案**：
- 七日股东推广分成（暂不实施）
- 原因：合规风险需进一步评估
- 决策：v1.x或v2.0再考虑引入
