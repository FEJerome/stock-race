# 法律咨询提示词 - 法行宝

## 项目背景

我正在开发一个微信小程序，产品定位是"AI股票竞赛平台"。核心玩法是：

- 用户作为"投资经理"，使用虚拟货币"元宝"雇佣AI大模型作为"交易员"
- AI交易员根据用户配置的策略（风险偏好、持仓周期等）进行虚拟股票交易
- 使用A股真实行情数据（非模拟数据），但所有交易均为虚拟，不涉及真实资金
- 用户通过对比不同AI交易员的收益率，体验不同大模型的"炒股能力"

## 核心功能模块

1. **虚拟交易系统**：用户使用"元宝"（虚拟货币）进行虚拟买卖A股，盈亏均为虚拟
2. **排行榜系统**：展示不同用户AI交易员的收益率排名，按时间维度（日/月/季/年）分类
3. **新闻服务**：采集财经新闻，供AI交易员决策参考（用户也可查看）
4. **等级/邀请系统**：用户通过活跃度和邀请好友获得经验值，提升等级解锁更多功能
5. **广告变现**：接入微信小程序流量主广告（ banner/激励视频）

## 需要确认的法律风险点

### 风险1：虚拟股票交易合规性（最高优先级）
- 用户使用虚拟货币进行虚拟A股交易，是否构成"非法经营证券业务"？
- 是否需要取得相关金融牌照（证券投资咨询、基金销售等）？
- 与"同花顺模拟炒股"、"雪球组合"等产品的合规边界在哪里？

### 风险2：排行榜展示合规性
- 公开展示AI交易员收益率排名，是否构成"荐股"或"投资建议"？
- 是否需要对收益率计算方式、风险提示做特殊声明？
- 是否需要在小程序注册时进行特殊类目申请？

### 风险3：财经新闻采集与展示
- 采集财经新闻数据并在小程序内展示，是否涉及新闻资质问题？
- 是否需要《互联网新闻信息服务许可证》？
- 仅展示新闻标题和摘要（不超过300字），是否属于"合理使用"？

### 风险4：虚拟货币"元宝"合规性
- 平台内使用"元宝"作为虚拟交易资金，是否涉及"网络博彩"？
- 用户通过观看广告获得元宝，是否构成"赌博筹码"？
- 元宝能否设置可兑换实物奖品？边界在哪里？

### 风险5：广告收入分成的合规性（暂缓实施）
- 若将流量主广告收入的一部分（如1%）作为"推广奖励"分发给邀请好友的用户，是否合规？
- 是否涉嫌"传销"或"非法集资"？
- 是否涉嫌"资金池"模式？

## 关键约束条件

- **目标平台**：微信小程序（需符合微信生态规范）
- **用户群体**：中国大陆用户
- **数据使用**：A股实时行情数据（从合法数据供应商购买）
- **盈利模式**：广告 + 月卡/年卡会员（去广告、解锁高级AI模型）

## 咨询问题

1. 上述5个风险点中，哪些是高风险必须解决才能上线？哪些可以暂缓？
2. 如果需要资质，申请流程和周期大概是怎样的？
3. 小程序注册时应选择什么类目？（当前考虑"工具-金融"或"生活服务"）
4. 用户协议和隐私政策中必须包含哪些特殊条款？
5. 是否建议先以"邀请制内测"方式规避部分风险？

---

**我的核心诉求**：在最小合规成本下，实现产品上线。如果某些功能存在高风险，我可以接受删减或延后。
