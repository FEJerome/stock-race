第一章：项目全景介绍

1.1 产品定位

AI财商训练场 = 用户投资策略的AI沙盒试验环境

核心体验：用户通过AI对话形成投资策略，AI作为执行工具在虚拟环境中自动化运行。

根本价值：让普通用户零基础、低精力耗费地验证自己的投资策略在虚拟股票中的实际表现。

技术载体：利用不同AI大模型的理解和执行能力，帮助用户测试策略有效性。

沙盒隔离机制（安全试验环境）

沙盒（Sandbox）设计理念：所有交易均在完全隔离的虚拟环境中进行，与真实证券市场零连接、零影响、零风险传递。
隔离维度 具体机制
资金隔离 纯虚拟资金，完全隔离真实资金，用户可进行零风险试错
市场隔离 仅模拟真实市场，不产生实际交易，不影响真实证券价格
环境隔离 每个AI交易员的策略独立运行，互不影响
数据隔离 完整记录决策过程用于学习复盘，数据不出沙盒环境

延伸价值（教育工具属性）

策略思维训练：通过AI对话形成策略的过程，帮助用户系统梳理投资逻辑，建立策略化思维框架。

零成本试错学习：沙盒环境支持长期观察策略效果，让用户在实践中理解策略与市场波动的关系。

决策复盘能力：完整记录AI决策过程与理由，辅助用户复盘分析，提升投资决策的纪律性。

1.2 用户旅程

注册 → 创建AI交易员 → 借助AI对话向交易员传达投资策略 → AI自动化虚拟交易 → 查看策略回测结果

第三章：真实存在的合规风险点

3.1 投资咨询业务风险

功能描述 AI基于用户策略生成交易决策理由（解释买卖逻辑）
风险描述 可能被认定为"向客户提供证券投资建议"
相关法规 《证券法》第120条（投资咨询业务需持牌）
用户输入颗粒度与风险分层示例：
颗粒度 用户输入示例 AI决策内容
精确 "茅台股价跌破1600元时买入10%，止损线1500元" 完全按用户指令执行，AI仅做执行记录
中等 "关注新能源板块，找两只龙头股长期持有" 在指定板块内选股，给出具体标的建议
模糊 "消费板块做价值投资，科技板块买涨杀跌" 需自主选股并给出买卖建议，可能触碰"荐股"红线
规避思路：通过AI对话引导机制，要求用户必须明确具体投资标的（股票代码或名称），不接受纯板块/概念的模糊策略。将AI角色定位为"策略执行者"而非"选股顾问"。
咨询问题：
  1. AI解释策略执行逻辑，是否构成"投资建议"？
  2. "策略执行报告"与"投资建议"的界限在哪里？
  3. 要求用户明确具体标的（禁止纯板块策略），是否能有效规避荐股风险？
  4. 如何设计才能明确属于"工具"而非"咨询服务"？

3.2 自动化交易执行风险

功能描述 AI根据用户预设策略自动执行虚拟买卖
风险描述 "自动化执行"概念可能被关联到"程序化交易"或"代客操作"
相关法规 《证券法》第137条、程序化交易相关监管规定
咨询问题：
  1. 虚拟环境的自动化执行，是否触碰任何监管红线？
  2. "用户策略的自动化执行工具"与"代客理财"的核心区别是什么？

3.3 排行榜与收益展示风险

功能描述 按收益率排序展示不同策略/AI的表现
风险描述 可能被视为"业绩展示"或"诱导性宣传"
相关法规 《广告法》第25条（金融广告不得承诺收益）
咨询问题：
  1. 虚拟策略回测结果的排行榜，是否违规？
  2. 需要哪些免责声明才能合规？
  3. 展示"夏普比率"等风险调整指标是否能降低风险？

3.4 经营性证券业务风险

功能描述 收费提供虚拟策略验证服务
风险描述 可能被认定为"从事经营性证券业务"
相关法规 《证券法》第118条（证券业务经营许可）
咨询问题：
  1. 收费提供"策略验证工具"是否属于经营性证券业务？
  2. "软件服务"与"证券服务"的界限在哪里？
