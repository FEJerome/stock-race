### 2. 实现细节

#### 2.1 指数加权平均 [INFERRED]

**注意**: 论文中未找到 λ=0.05 作为指数加权平均平滑因子的定义。

**EMA在论文中的实际应用** [CERTAIN]:

```
MACD计算:
- MACD线: M_t = EMA_12 - EMA_26
- 信号线: S_t = EMA_9(M_t)
- 柱状图: H_t = M_t - S_t

EMA平滑因子: α = 2/(t+1)

RSI计算:
- RS_t = AvgGain_t / AvgLoss_t
- 使用14天回望期的指数平滑移动平均 [11]
```

**指数加权远期收益** [CERTAIN]:
```
r_t = Σ(h=1 to H) ω_h · (p_{t+h+1}/p_{t+1} - 1)

其中:
- ω_h = η^h / Σ(i=1 to H) η^i  (归一化指数权重)
- η ∈ (0, 1) 为衰减因子
- H 为最大预测 horizon
```

**λ=0.05 的实际含义** [CERTAIN]:
- 在AlphaQuanter论文中，λ=0.001 代表交易费率 [12]
- 在行为金融学一致性验证中，α=0.05 是显著性水平，用于Mann-Whitney U检验 [13]

#### 2.2 窗口特征计算 [INFERRED]

论文未明确描述"净预期值"、"主导情绪"、"逻辑一致性"这三个特征，但以下机制可作为实现参考：

**净预期值 → 置信度得分** [INFERRED]:
```
θ_ij = E[IC(α_ij^(t) | M(t))]

其中:
- θ_ij: alpha因子α_ij的置信度得分
- IC: 信息系数（预测alpha与实际收益的相关系数）
- M(t): 市场条件
```

**主导情绪 → 市场情绪评分** [CERTAIN]:
- News-Sentiment Agent输出整体市场情绪评分（bullish/bearish/neutral）
- 评分范围: 0-1 或 -1 到 +1
- 基于新闻影响分数计算: N_t = 0.55·base(t) + 0.25·prob(t) + 0.20 [14]

**逻辑一致性 → 决策一致性验证** [INFERRED]:
- 检查动量、振荡器、波动率指标间是否存在逻辑冲突
- 技术分析Agent验证指标间的一致性 [15]
- 推理轨迹记录确保决策过程可审计 [16]

**窗口特征计算示例** [CERTAIN]:
```python
# 多尺度动量评分 (FinRS)
M_t = M_t^s + M_t^m + M_t^l

其中:
- M_t^s = price[t+1] - price[t]      (1天短期趋势)
- M_t^m = price[t+7] - price[t]      (7天中期趋势)
- M_t^l = price[t+30] - price[t]     (30天长期趋势)
```

|----------------|----------------|------|
| NO | NO | EQUAL |
| YES | YES | VAGUE |
| YES | NO | BEFORE |
| NO | YES | AFTER |

### 4. 验证方式

#### 4.1 分层回测验证 [CERTAIN]

**回测方法**:
1. 根据预测概率/因子值对股票排序
2. 平均分为5层（每层20%）
3. 第1层=最可能上涨，第5层=最可能下跌
4. 计算第1层与第5层的收益差(E) [20]

**收益差公式** [CERTAIN]:
```
E = Σ(t=1 to 30) [Σ(s∈A) SF_a/cnt1 - Σ(s∈B) SF_a/cnt2] - Σ(t=1 to 30) SF_a'/30

其中:
- SF_a: 单只股票当天因子值
- A: 因子值前20%的股票
- B: 因子值后20%的股票
- cnt1, cnt2: 对应层股票数量
- SF_a': 中证500总收益率（基准）
- E越大表示分层效果越好
```

**实验结果** [CERTAIN]:
- 引入事件时间三元组后，模拟总收益差提升0.0323
- 30天回溯期效果最佳（vs 1天、15天）

#### 4.2 消融实验 [CERTAIN]

**组件移除测试**:
| 移除组件 | Out-of-sample IC下降 | Sharpe Ratio下降 |
|---------|---------------------|------------------|
| Confidence Score Agent | 31.9% | 22.5% |
| Risk Preference Agent | - | 显著下降 |
| Risk Management模块 | 累计收益下降 | - |
| Self-Reflection机制 | 性能下降 | - |

#### 4.3 统计检验 [CERTAIN]

**Mann-Whitney U检验**:
- 显著性水平: α = 0.05
- 效应量指标: CLES, r_rb, δ_Cliff
- 验证指标: p < 0.05 且 CLES > 0.5 [13]

**信息系数(IC)验证**:
- IC = σ(u, v) （预测alpha与实际收益的相关系数）
- 高IC表示因子预测能力强 [21]

### 关键公式/算法

#### 1. 指数加权移动平均
```python
def ema(values, alpha=None, span=None):
    """
    指数加权移动平均
    alpha: 平滑因子 (若未指定，从span计算: alpha = 2/(span+1))
    """
    if alpha is None and span is not None:
        alpha = 2 / (span + 1)

    result = []
    ema_prev = values[0]
    for value in values:
        ema_curr = alpha * value + (1 - alpha) * ema_prev
        result.append(ema_curr)
        ema_prev = ema_curr
    return result
```

#### 2. 多尺度动量评分
```python
def multi_scale_momentum(prices, t):
    """
    计算多尺度动量评分 (FinRS方法)
    """
    M_s = prices[t+1] - prices[t]           # 1天短期
    M_m = prices[t+7] - prices[t]           # 7天中期
    M_l = prices[t+30] - prices[t]          # 30天长期

    M_t = M_s + M_m + M_l                   # 聚合动量评分
    return M_t
```

#### 3. 分层回测收益差计算
```python
def calculate_return_spread(factor_values, returns, n_layers=5):
    """
    计算分层回测收益差
    """
    # 按因子值排序分层
    sorted_stocks = sorted(factor_values.items(), key=lambda x: x[1])
    layer_size = len(sorted_stocks) // n_layers

    # 第1层（最高因子值）和第5层（最低因子值）
    top_layer = sorted_stocks[-layer_size:]
    bottom_layer = sorted_stocks[:layer_size]

    # 计算各层平均收益
    top_return = sum(returns[s[0]] for s in top_layer) / len(top_layer)
    bottom_return = sum(returns[s[0]] for s in bottom_layer) / len(bottom_layer)

    return top_return - bottom_return  # 收益差E
```
