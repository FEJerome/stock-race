# 关键研究与复审证据

本目录保存从项目过程目录精选的长期证据，目标是让新设备仅凭 Git 即可理解当时的研究结论、复审范围与实际验证结果。它不是完整过程目录，也不代表所有文件均在当前版本重新运行过。

## 目录

| 目录 | 内容 | 保留理由 |
|---|---|---|
| `v3-data-probe/` | V3 数据源探针的原始 CSV、标准化 JSON、manifest 与探针脚本 | 支持复核数据源选择、字段理解与归一化过程 |
| `sr006-s0-qa/` | S0 零上下文独立复审报告 | PASS 结论、50 项测试、补充复测及未验证边界 |
| `sr007-s1-qa/` | S1 独立复审总结、完整检查退出码与环境 | PASS 结论、89 项测试、独立复算及未验证边界 |
| `sr008-s2-qa/` | S2 独立复验总结 | PASS、22/22 复验通过及主要风险回归结果 |

## 收录边界

- 不收录 `venv`、`__pycache__`、`.pyc` 或其他可再生依赖。
- 不收录重复修复日志、mutation 日志、临时 CLI、构建缓存与过程截图。
- 不收录第三方外部评审原始包；其正式结论已由研究文档承载。
- 不收录 `.env.production` 或任何真实凭据。
- 复审报告中的环境、commit 和结论均属于当时现场；后续复用时须重新核对当前 HEAD，不将历史 PASS 自动视为当前版本通过。
