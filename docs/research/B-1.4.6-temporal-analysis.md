## 研究发现

### 1. [核心方法] 布尔问答法原理

**[CERTAIN]** 论文提出的布尔问答法核心原理：

传统方法将时序关系判断视为4分类任务（BEFORE/AFTER/EQUAL/VAGUE），但这种方式忽略了关系之间的内在逻辑依赖性。论文参考Cohen的方法，将四种时间关系通过事件的开始时间点来解释，转化为布尔回答任务。

**为什么用2个二分类替代4分类**：
- 传统多标签分类将每种关系简单视为单标签，抹杀了关系的内在依赖性
- 布尔问答法通过两个YES/NO问题捕捉关系的逻辑结构：
  - 问题1：事件A是否可能先于事件B发生？
  - 问题2：事件B是否可能先于事件A发生？
- 这种方法将复杂的关系判断简化为简单的二分类选择，更易于模型学习和推理

**四种时序关系定义** [CERTAIN]：
| 关系 | 定义 |
|------|------|
| BEFORE | A事件在B事件之前发生 |
| AFTER | A事件在B事件之后发生（等价于B BEFORE A）|
| EQUAL | A和B事件同时发生 |
| VAGUE | A和B事件的发生时间难以确定 |

### 2. [实现细节] 具体实现方法

#### 2.1 Before/After 二分类的 Prompt 设计

**[CERTAIN]** 时间关系判断Prompt模板：

```
指示：
你是一个时间关系分类器，对于输入的一段文本及其包含的两个事件A与B，
根据事件发生时间顺序和逻辑关系，判断事件A是否可能先于事件B发生，
返回"YES"或"NO"。
文本中所有事件使用event[id]进行标识，其中event代表事件触发词，id代表事件编号。

例子：
Input: 小红吃[0]完早饭，才去上班[1]。
eventA:吃[0]
eventB:上班[1]
Output: "YES"

输入：
Input: <NewsContent>
eventA: <EventA>
eventB: <EventB>
Output:
```

**使用时填充**：
- `NewsContent`：对应的新闻舆情文本
- `EventA`：事件A文本（含编号）
- `EventB`：事件B文本（含编号）

#### 2.2 概率阈值设定策略

**[UNKNOWN]** 论文未明确提及概率阈值设定策略。

论文采用的是YES/NO硬输出方式，而非概率判断。模型直接返回"YES"或"NO"，不涉及概率阈值 cutoff。

**[INFERRED]** 建议实现时可考虑：
- 若使用生成式模型，可基于token概率计算置信度
- 建议阈值：当YES/NO的softmax概率 > 0.7时采信，否则标记为VAGUE

#### 2.3 关系判定逻辑（组合规则）

**[CERTAIN]** 时间关系规则表：

| 问题1 (A先于B?) | 问题2 (B先于A?) | 时间关系 |
|-----------------|-----------------|----------|
| NO | NO | EQUAL |
| YES | YES | VAGUE |
| YES | NO | BEFORE |
| NO | YES | AFTER |

**判定流程**：
1. 对事件对(A, B)执行问题1，得到回答R1
2. 对事件对(A, B)执行问题2，得到回答R2
3. 根据上表规则匹配，得到最终时间关系

#### 2.4 时序链构建算法

**[UNKNOWN]** 论文未明确描述拓扑排序算法。

论文仅提及构建"事件时间三元组集合"，未详细说明如何构建时序链或进行拓扑排序。

**[INFERRED]** 基于论文描述，建议的时序链构建方法：

```python
# 伪代码：基于事件时间三元组的时序链构建
def build_temporal_chain(event_triplets):
    """
    输入：事件时间三元组列表 [(eventA, eventB, relation), ...]
    输出：按时间排序的事件列表
    """
    # 构建有向图
    graph = defaultdict(list)
    in_degree = defaultdict(int)

    for eventA, eventB, relation in event_triplets:
        if relation == "BEFORE":
            graph[eventA].append(eventB)
            in_degree[eventB] += 1
        elif relation == "AFTER":
            graph[eventB].append(eventA)
            in_degree[eventA] += 1
        # EQUAL和VAGUE不添加边

    # 拓扑排序
    queue = [e for e in all_events if in_degree[e] == 0]
    sorted_events = []

    while queue:
        event = queue.pop(0)
        sorted_events.append(event)
        for next_event in graph[event]:
            in_degree[next_event] -= 1
            if in_degree[next_event] == 0:
                queue.append(next_event)

    return sorted_events
```

4. 根据规则表判定时间关系
5. 输出事件时间三元组

## 给开发者的实现指导

### 关键算法

```python
class TemporalRelationAnalyzer:
    """时序关系分析器 - 布尔问答法实现"""

    RELATIONS = ["BEFORE", "AFTER", "EQUAL", "VAGUE"]

    # 判定规则表：(问题1回答, 问题2回答) -> 关系
    RULES = {
        ("NO", "NO"): "EQUAL",
        ("YES", "YES"): "VAGUE",
        ("YES", "NO"): "BEFORE",
        ("NO", "YES"): "AFTER"
    }

    def __init__(self, model_client):
        self.model = model_client
        self.prompt_template = """你是一个时间关系分类器，对于输入的一段文本及其包含的两个事件A与B，
根据事件发生时间顺序和逻辑关系，判断事件A是否可能先于事件B发生，返回"YES"或"NO"。
文本中所有事件使用event[id]进行标识，其中event代表事件触发词，id代表事件编号。

Input: {news_content}
eventA: {event_a}
eventB: {event_b}
Output:"""

    async def classify_pair(self, news_content: str, event_a: dict, event_b: dict) -> str:
        """判断两个事件的时序关系"""
        # 问题1：A是否先于B
        prompt1 = self.prompt_template.format(
            news_content=news_content,
            event_a=self._format_event(event_a),
            event_b=self._format_event(event_b)
        )
        answer1 = await self.model.ask_yes_no(prompt1)

        # 问题2：B是否先于A（调换顺序）
        prompt2 = self.prompt_template.format(
            news_content=news_content,
            event_a=self._format_event(event_b),
            event_b=self._format_event(event_a)
        )
        answer2 = await self.model.ask_yes_no(prompt2)

        # 规则匹配
        return self.RULES.get((answer1, answer2), "VAGUE")

    async def analyze(self, news_content: str, events: list) -> list:
        """分析所有事件对的时序关系"""
        triplets = []
        for i, event_a in enumerate(events):
            for event_b in events[i+1:]:
                relation = await self.classify_pair(news_content, event_a, event_b)
                triplets.append({
                    "eventA": event_a,
                    "eventB": event_b,
                    "relation": relation
                })
        return triplets

    def _format_event(self, event: dict) -> str:
        return f"{event['Trigger']}[{event['Id']}]"
```

### 需要注意的实现细节

1. **模型微调**：论文使用LoRA技术对本地大模型进行微调，而非全参数微调
2. **事件标识**：Prompt中使用`event[id]`格式标识事件位置（如"吃[0]"）
3. **上下文学习**：Prompt中包含具体示例（few-shot learning）
4. **计算复杂度**：n个事件需要判断 n*(n-1)/2 对关系
5. **关系对称性**：BEFORE和AFTER是互逆关系，可优化减少一半计算

# 测试规则表
def test_temporal_rules():
    analyzer = TemporalRelationAnalyzer(mock_model)
    assert analyzer.RULES[("NO", "NO")] == "EQUAL"
    assert analyzer.RULES[("YES", "YES")] == "VAGUE"
    assert analyzer.RULES[("YES", "NO")] == "BEFORE"

# 测试对称性

    # BEFORE和AFTER应该是互逆的
    if relation(A, B) == "BEFORE":
        assert relation(B, A) == "AFTER"

### 集成测试用例
