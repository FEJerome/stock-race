# 模块依赖关系文档

最后更新：2026-01-29
维护者：协调智能体

## 📋 概述

本文档记录项目各模块间的依赖关系、接口定义和变更影响。所有跨模块依赖必须在此文档中明确记录，以便协调开发和变更管理。

## 🔗 核心依赖关系图

```
前端组件 → 前端组合式函数 → 前端API客户端 → 后端API路由 → 后端服务 → 后端适配器
     ↓           ↓               ↓              ↓           ↓          ↓
前端工具函数 ←─────────────── 后端工具模块（编码、解析、生成）
```

## 📦 模块间依赖详情

### 1. 前端组件模块 → 前端组合式函数模块
**依赖内容**：状态管理、业务逻辑、数据处理
**接口定义**：
- `useNovelCrawler()` 提供爬虫状态和操作方法
- `useErrorHandler()` 提供错误处理逻辑
- `useDataProcessor()` 提供数据转换功能

**变更影响**：
- 修改组合式函数API需要更新组件调用
- 数据格式变更需要同步更新组件显示逻辑

**负责人**：前端组件智能体 + 前端逻辑智能体
**状态**：稳定
**最后验证**：2026-01-29

### 2. 前端组合式函数 → 前端API客户端模块
**依赖内容**：HTTP请求封装、API调用方法
**接口定义**：
- `novelApi.crawl(url)` 启动爬取任务
- `novelApi.getStatus(taskId)` 获取任务状态
- `novelApi.generateTxt(data)` 生成TXT文件
- `novelApi.downloadFile(filename)` 下载文件

**变更影响**：
- API方法签名变更需要更新组合式函数调用
- 错误响应格式变更需要更新错误处理逻辑

**负责人**：前端逻辑智能体 + 前端逻辑智能体（API部分）
**状态**：稳定
**最后验证**：2026-01-29

### 3. 前端API客户端 → 后端API路由模块
**依赖内容**：REST API端点、请求/响应格式
**接口定义**：
- `POST /api/crawl` 请求格式：`{ url: string }`
- `GET /api/status/:taskId` 响应格式：`{ status, progress, data }`
- `POST /api/generate-txt` 请求格式：`{ title, author, chapters }`
- `GET /api/download/:filename` 响应：文件流
- `GET /api/tasks` 响应：任务列表
- `DELETE /api/tasks/:taskId` 删除任务

**变更影响**：
- API端点变更需要前后端同步更新
- 数据格式变更需要双向兼容处理

**负责人**：前端逻辑智能体（API） + 后端服务智能体（路由）
**状态**：稳定（需要验证）
**最后验证**：2026-01-29

### 4. 后端API路由 → 后端服务模块
**依赖内容**：服务方法调用、业务逻辑处理
**接口定义**：
- `crawlerService.startCrawl(url)` 启动爬取服务
- `crawlerService.getTaskStatus(taskId)` 获取任务状态
- `crawlerService.generateTxtFile(data)` 生成TXT文件
- `fileService.downloadFile(filename)` 提供文件下载

**变更影响**：
- 服务方法变更需要更新路由调用
- 业务逻辑变更可能影响API行为

**负责人**：后端服务智能体（路由+服务）
**状态**：稳定
**最后验证**：2026-01-29

### 5. 后端服务模块 → 后端适配器模块
**依赖内容**：网站适配器、数据提取逻辑
**接口定义**：
- `BaseAdapter` 基类接口
- `XinyushuwuAdapter` 具体实现
- `adapter.extractContent(html)` 内容提取方法
- `adapter.getNextPageUrl(html)` 下一页URL提取

**变更影响**：
- 适配器接口变更需要更新服务调用
- 数据提取逻辑影响爬取结果质量

**负责人**：后端服务智能体 + 后端适配器智能体
**状态**：稳定（需要优化）
**最后验证**：2026-01-29

### 6. 所有模块 → 后端工具模块
**依赖内容**：编码转换、HTML解析、文件生成工具
**接口定义**：
- `EncodingUtils.convertToUtf8(buffer, encoding)` 编码转换
- `EncodingUtils.smartDecodeResponse(response)` 智能解码
- `HtmlParser.parse(html)` HTML解析
- `TxtGenerator.generate(content)` TXT文件生成

**变更影响**：
- 工具方法变更影响所有使用模块
- 编码处理逻辑影响数据正确性

**负责人**：后端工具智能体
**状态**：需要优化（编码问题）
**最后验证**：2026-01-29

### 7. 前端组件 → 前端工具模块
**依赖内容**：URL验证、文本格式化、工具函数
**接口定义**：
- `urlUtils.validate(url)` URL验证
- `urlUtils.format(url)` URL格式化
- `textUtils.clean(text)` 文本清理
- `textUtils.truncate(text, length)` 文本截断

**变更影响**：
- 工具函数变更需要更新组件调用
- 验证逻辑变更影响用户输入处理

**负责人**：前端组件智能体 + 前端逻辑智能体（工具）
**状态**：待开发
**最后验证**：2026-01-29

## ⚠️ 当前依赖问题

### 1. 编码转换依赖问题
**问题描述**：后端工具模块的编码转换功能可能存在乱码问题
**影响模块**：后端适配器 → 后端工具 → 所有数据流经模块
**状态**：`blocked`
**优先级**：高
**解决方案**：需要后端工具智能体优先解决编码测试

### 2. 网络稳定性依赖
**问题描述**：网络请求重试机制需要验证有效性
**影响模块**：后端适配器 → 后端服务 → 前端API调用链
**状态**：`testing`
**优先级**：高
**解决方案**：后端服务智能体测试网络重试逻辑

### 3. API响应格式统一
**问题描述**：需要统一前后端API数据格式
**影响模块**：前端API客户端 ↔ 后端API路由
**状态**：`pending`
**优先级**：中
**解决方案**：协调智能体组织接口规范制定
