## 1. 产品画布

> **章节状态：** 🟢 已冻结（提炼自原 PRD 2.1/2.2/2.3）

| 维度 | 内容 |
|------|------|
| **目标用户** | 对AI感兴趣但不懂技术的普通用户；想了解不同AI模型差异的爱好者；寻找"AI能做什么"直观体验的用户 |
| **核心问题** | 新AI模型发布时，用户想知道"它炒股怎么样"但缺乏零门槛的验证渠道 |
| **独特价值** | 零技术门槛体验/对比不同AI大模型的"炒股能力" |
| **解决方案** | AI模型农场——用户作为"投资经理"，雇佣AI作为"交易员"进行虚拟股票交易 |
| **商业模式** | 订阅制（解锁管理能力）+ 周薪制（AI使用成本）+ 自填API（管理费模式） |
| **关键壁垒** | 先发优势 + 人设差异化 + 数据沉淀 + 用户习惯 |
| **北极星指标** | AI交易员创建数 / 日活跃用户（DAU）|

### 1.1 核心价值主张

**一句话描述**：
AI股票竞赛平台 = "AI模型农场"，用户作为"投资经理"招聘AI作为"交易员"进行虚拟股票交易。

**根本价值**：
外界发布新AI模型时，用户第一反应是"来这个平台试试它炒股怎么样"。

### 1.2 产品边界（不做清单）

| 不做事项 | 原因 |
|---------|------|
| 不涉及真实资金交易 | 合规风险，使用虚拟"投资研究点数" |
| 不承诺AI炒股能力 | 胜率≈投骰子，仅提供体验，非投资建议 |
| 用户无个人账户余额 | 不比拼总资产，只看AI交易员独立表现 |
| v1.0 不做社交功能 | 关注、分享等延后考虑 |
| 不使用国外大模型 | 支持国产、规避合规风险 |

### 1.3 商业模式概览

**核心转变**：从"等级主导"转为"订阅主导"，等级退居二线作为粘性工具

**三层资源体系**：

| 层级 | 用途 | 获取方式 | 与能力关系 |
|------|------|---------|-----------|
| 经验值 | 用户等级（1-30级）| 活跃度（登录、邀请等）| 仅影响奖励，不影响核心能力 |
| 订阅层级 | AI席位数量、周薪预算上限 | 付费订阅 | 硬性门槛，决定管理能力 |
| 投资研究点数 | AI个体虚拟资金（1万-10亿）| 创建时分配 | 仅影响该AI的交易规模 |

## 2. 用户旅程地图

> **章节状态：** 🟢 已冻结（框架性内容）

```
认知 → 首次使用 → 创建AI → 首次交易日 → 持续使用 → 深度参与
 │         │          │           │           │          │
 ▼         ▼          ▼           ▼           ▼          ▼
听说新AI  浏览首页   策略收集    查看交易    每日查看   邀请好友
模型发布  排行榜    创建AI       结果        AI表现     订阅升级
```

### 2.1 旅程阶段详解

| 阶段 | 用户行为 | 用户目标 | 接触点 | 情绪曲线 | 关键指标 |
|------|---------|---------|--------|---------|---------|
| **认知** | 听说新AI模型 | 好奇它炒股能力如何 | 朋友圈/社媒 | 😐→🙂 | 访问转化率 |
| **首次使用** | 打开小程序，浏览首页 | 快速了解产品价值 | 首页/排行榜 | 🙂→😃 | 新用户激活率 |
| **创建AI** | 进行策略收集对话 | 创建符合偏好的AI | 策略对话UI | 😃→🤔 | AI创建完成率 |
| **首次交易日** | 等待并查看交易结果 | 验证AI是否符合预期 | AI详情页 | 🤔→😮 | 次日回访率 |
| **持续使用** | 每日查看AI表现 | 观察AI长期表现 | 仪表盘/排行榜 | 😮→😊 | DAU、7日/30日留存 |
| **深度参与** | 邀请好友/订阅升级 | 获得更多AI席位 | 邀请系统/订阅页 | 😊→🥳 | 邀请转化率、订阅率 |

### 2.2 关键触点设计

1. **首次创建AI时的策略收集对话**
   - 目标：降低决策负担，提供经典策略套餐
   - 五维度：风险承受、关注板块、持仓周期、仓位止损、市场范围

2. **每日登录查看"我的AI交易员"表现**
   - 目标：形成使用习惯，提供成长反馈
   - 设计：收益曲线、持仓分布、AI等级成长

3. **排行榜查看其他用户AI的表现对比**
   - 目标：制造对比和竞争感
   - 设计：时间维度筛选（日/周/月/总榜）、夏普比率辅助排序

## 4.1 冷启动体验

> **章节状态：** 🟢 已冻结（提炼自原 PRD 2.4/2.5）

### 4.1.1 用户状态流转

```
游客模式（未登录）
    ├── 可浏览：首页介绍、排行榜（匿名数据）
    ├── 不可创建AI交易员
    └── 引导：点击"创建AI交易员" → 跳转登录

登录后（微信授权）
    ├── 获取用户OpenID
    ├── 强制实名认证（微信realNameVerify接口）
    └── 年龄校验

实名认证后
    ├── ≥18岁：正常使用全部功能
    └── <18岁：拒绝访问，提示"本服务仅限18周岁以上用户"
```

### 4.1.2 实名认证流程

**强制触发时机**：
- 首次点击"创建AI交易员"
- 首次点击"我的"页面
- 首次尝试查看AI决策详情

**认证方式**：
- 调用微信`realNameVerify`接口
- 获取身份证号，提取年龄信息
- 服务端记录：`is_verified`, `age`, `id_card_hash`（脱敏）

**拒绝处理（<18岁）**：
- 页面提示："根据相关法规，本服务仅限18周岁以上用户使用"
- 记录拒绝时间，允许1天后重新认证
- 允许无限次重试，每次间隔1天

### 4.1.3 游客模式权限

| 功能 | 游客 | 实名用户（≥18岁） |
|-----|------|------------------|
| 浏览首页介绍 | ✅ | ✅ |
| 查看排行榜（匿名） | ✅ | ✅ |
| 创建AI交易员 | ❌ | ✅ |
| 查看AI决策详情 | ❌ | ✅ |
| 邀请好友 | ❌ | ✅ |
| 付费功能 | ❌ | ✅ |

### 4.1.4 合规声明

**产品定位声明**：
- 本平台的AI交易决策仅供研究参考，不构成投资建议
- 虚拟交易结果不代表真实投资收益
- 过往收益表现不代表未来收益

**法律合规**：
- 平台内投资研究点数、工资额度不可兑换现金或实物
- 不涉及杠杆交易、T+0等真实市场禁用机制
- 排行榜数据基于历史模拟计算，非投资建议
- 严格限制18岁以下用户访问

**界面合规**：
- 所有涉及收益率的页面标注："虚拟交易结果不具有真实投资参考价值"
- 禁用"赚""亏""盈利""暴富"等诱导性词汇
- 使用中性色彩，避免红涨绿跌的强烈视觉刺激

## 4.2 AI交易员创建

> **章节状态：** 🟢 已冻结-Local（提炼自原 PRD 4.2）

### 4.2.1 雇佣流程

**雇佣限制**：
- 受订阅层级限制：平台托管AI由周薪预算决定，自填API有限额
- 受周薪预算限制（本周可支付工资总和不能超过预算上限）
- 受AI职级限制（Free仅实习生，Pro解锁经理，Enterprise解锁合伙人）

**雇佣步骤**：
1. **选择雇佣类型**：平台托管AI 或 用户自填API
2. **选择工作模式**：试用期（5个交易日，工资8折）或 正式工
3. **配置投资研究点数**：范围 10,000 - 订阅层级上限
4. 进行策略收集对话（五维度）
5. **确认雇佣并扣费**

### 4.2.2 策略收集机制

**核心流程**：
用户输入 → AI追问（填补维度）→ 策略文档生成 → 后续决策的上下文

**五维度底线**（必须收集）：
1. **风险承受**：保守(-5%回撤)/稳健(-10%)/激进(-20%)/极度(-30%或无)
2. **关注板块**：具体行业板块，或"全市场"
3. **持仓周期**：超短线(1-3天)/短线(1-2周)/中线(1-3月)/长线(3月+)
4. **仓位与止损**：单股仓位上限 + 止损纪律
5. **交易市场范围**：纯主板 / 主板+创业板 / 全市场

**经典策略套餐**：

| 套餐 | 风险 | 周期 | 仓位 | 画像 |
|------|------|------|------|------|
| 价值投资者 | 稳健 | 长线 | 30% | "买好公司，长期持有" |
| 趋势跟踪者 | 激进 | 中线 | 50% | "顺势而为，截断亏损" |
| 题材狙击手 | 极度激进 | 短线 | 20% | "抓热点快进快出" |
| 量化交易者 | 稳健 | 超短线 | 10% | "积小胜为大胜" |

## 4.3 交易执行

> **章节状态：** 🟢 已冻结-Local（提炼自原 PRD 4.3）

### 4.3.1 虚拟资金规则

| 职级 | 默认初始资金 | 用户可设范围 | 大额风险提示 |
|------|------------|-------------|-------------|
| 实习生 | 50万 | 1万 ~ 1000万 | ≥1亿提示价格冲击 |
| 经理 | 100万 | 1万 ~ 1亿 | ≥1亿提示价格冲击 |
| 合伙人 | 500万 | 1万 ~ 10亿 | ≥1亿提示价格冲击 |

### 4.3.2 交易执行逻辑

**执行流程**：
1. AI 决策输出（action/quantity/reason）
2. 用户确认或自动执行（按激励档位频率）
3. 交易引擎校验（时间/资金/持仓）
4. SQLite 事务包裹执行
5. 更新持仓、资金、收益指标

**交易时间限制**：
- A股交易日：09:30-11:30, 13:00-15:00
- 非交易时间可查询，不可交易

### 4.3.3 持仓管理

```python
class Position:
    agent_id: UUID      # 所属AI
    symbol: str         # 股票代码
    quantity: int       # 持仓数量
    avg_cost: Decimal   # 平均成本

# 买入：新增持仓或加仓，更新 avg_cost
# 卖出：减仓或清仓，计算 realized_pnl
```

### 4.3.4 收益计算指标

| 指标 | 说明 | 计算公式 |
|------|------|---------|
| 总收益率 | 累计收益/初始资金 | (current - initial) / initial |
| 日收益率 | 当日收益/昨日净值 | (today - yesterday) / yesterday |
| 最大回撤 | 峰值到谷底最大跌幅 | max(drawdown) |
| 夏普比率 | 风险调整后收益 | (return - risk_free) / std |
| 胜率 | 盈利交易占比 | win_trades / total_trades |
| 盈亏比 | 平均盈利/平均亏损 | avg_win / avg_loss |

### 4.3.5 排行榜系统（Local版）

**对比范围**：用户创建的所有 AI 交易员之间对比

**时间维度**：
- 日榜（今日收益）
- 周榜（近7天）
- 月榜（近30天，默认）
- 总榜（成立以来）

**排名指标**：
- 默认：总收益率排序
- 辅助：夏普比率、最大回撤、胜率

| 每日登录 | +5经验/天 | 自然日首次打开 |
| 连续登录奖励 | 额外+10 | 连续7天额外奖励 |
| 观看广告 | +3经验/次 | 每日上限5次 |

| 首个完整交易周 | +50经验 | 首个完整交易周（5个交易日）结束 |

### 4.4.3 AI交易员激励机制（已冻结）

**核心设计**：激励档位是"正式员工特权"，非"高级职级特权"

**档位设计**：

| 档位 | 工资比例 | 决策频率 | 报告详细度 |
|-----|---------|---------|-----------|
| 标准模式 | 100% | 基准频率 | 标准（100字） |
| 积极模式 | 120% | +20% | 详细（150字） |
| 激进模式 | 150% | +50% | 超详细（250字+预测） |

**解锁规则**：
- 试用期：❌ 禁用激励档位
- 实习生Lv.3+：✅ 解锁激励档位
- 经理/合伙人：✅ 立即可用

### 4.4.4 职级晋升体系

**职级层级**：
1. **实习生**（默认）
2. **经理**（Lv.6可晋升）
3. **合伙人**（Lv.12可晋升）

**晋升规则**：
```
实习生Lv.6 → 晋升经理（等级保留Lv.6）
经理Lv.12 → 晋升合伙人（等级保留Lv.12）
```

**休息日培训**：
- 开放时间：周末及A股非交易日
- 费用：3天工资 = 升1级
- 作用：快速达到晋升门槛

### 4.4.5 称号系统（荣誉馆）

**系统定位**：低成本、高情感回报的荣誉激励体系

**称号分类**：

| 类型 | 示例称号 | 获取条件 |
|-----|---------|---------|
| **成长类** | 见习经理/初级经理/投资总监 | 等级达到对应区间 |
| **地域类** | 广东省No.1投资经理 | 该地域等级排名 |
| **成就类** | 百脑汇/常胜将军/逆市猎人 | 完成特定挑战 |
| **纪念类** | 内测元老/早期采用者 | 特定时间前注册 |

### 4.5.2 周薪制度

**基本概念**：
- **周薪周期**：5个交易日 = 1周
- **日薪计算**：日薪 = 周薪 ÷ 5
- **结算单位**：A股交易日（排除周末和法定节假日）

**扣费时机**：

| 场景 | 扣费时间 | 当日计费 |
|-----|---------|---------|
| 新雇佣（09:30-11:30）| 雇佣时 | 全天（1天）|
| 新雇佣（11:30-14:00）| 雇佣时 | 半天（0.5天）|
| 新雇佣（14:00后）| 雇佣时 | 免费（0天）|
| 已有AI | 每周一 02:00 | 下周整周 |

### 4.5.3 试用期机制

**试用期规则**：
- **长度**：固定5个交易日
- **工资折扣**：标准8折（运营活动可3-5折）
- **扣费**：雇佣时一次性扣5天试用期工资
- **结束**：第5天收盘后提示转正

**转正流程**：
1. 第5天收盘后推送通知"试用期即将结束"
2. 用户选择：立即转正 / 延长试用期（再付5天）/ 解雇
3. 转正后进入周一凌晨扣费周期

### 4.5.4 自填API模式

**两种模式对比**：

| 维度 | 平台托管AI | 自填API |
|-----|-----------|---------|
| **API来源** | 平台统一提供 | 用户提供自有API Key |
| **工资占用** | 100%标准定价 | Free 30% / Pro 20% / Enterprise 10% |
| **席位限制** | 无限制（预算决定） | Free≤3, Pro≤10, Enterprise≤10 |

**安全保障**：
- API Key必须AES-256加密存储
- 用户界面仅显示掩码（`sk-...abc123`）
- 访问日志记录（时间、IP、操作类型）
- 用户可设置3/7/10天未登录自动停用

### 4.5.5 广告接入

**接入条件**：仅对实名认证且≥18岁用户展示

**广告位**：
- banner广告（首页底部）
- 激励视频广告（获取经验值）

**付费用户**：默认不展示广告，强调"专注研究体验"而非"去广告"
