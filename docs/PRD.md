## 2. 战略层（产品是什么）

### 2.1 产品定位 【已冻结】

**一句话描述**：
AI股票竞赛平台 = "AI模型农场"，用户作为"投资经理"招聘AI作为"交易员"进行虚拟股票交易。

**核心价值主张**：
让普通用户零技术门槛地体验/对比不同AI大模型（DeepSeek、通义千问、Kimi等）的"炒股能力"。

**目标用户**：
- 对AI感兴趣但不懂技术的普通用户
- 想了解不同AI模型差异的爱好者
- 寻找"AI能做什么"直观体验的用户

**根本价值**：
外界发布新AI模型时，用户第一反应是"来这个平台试试它炒股怎么样"。

### 2.2 产品边界（不做清单）【已冻结】

| 不做事项 | 原因 |
|---------|------|
| 不涉及真实资金交易 | 合规风险，使用虚拟"元宝" |
| 不承诺AI炒股能力 | 胜率≈投骰子，仅提供体验，非投资建议 |
| 用户无个人账户余额 | 不比拼总资产，只看AI交易员独立表现 |
| v1.0 不做社交功能 | 关注、分享等延后考虑 |
| 不使用国外大模型 | 支持国产、规避合规风险 |

### 2.3 商业模式 【已更新 - 2026-03-04】

**核心转变**：从"等级主导"转为"订阅主导"，等级退居二线作为粘性工具

**商业逻辑**：
- API调用是刚性成本，免费必须有边界
- 订阅是收入来源（"房租"），工资是服务成本（"人工"）
- 等级系统作为日常粘性工具，类似QQ等级，提供正反馈但非核心能力

---

#### 三层资源体系

**1. 经验值 → 等级系统（粘性工具）**
- 用户通过活跃度获得经验值，用于30级等级提升
- 等级提供小奖励（称号、试用券、订阅折扣等），不影响核心能力
- 参考QQ等级模式：初期用户在意，后期纯装饰

**2. 订阅层级 → 管理能力（核心付费）**
- 订阅解锁"公司管理能力"：AI席位数量、周薪预算上限
- 与等级系统独立，订阅是硬性门槛

| 层级 | 价格 | 平台托管席位 | 自填API席位 | 周薪预算 | 自填工资占用 | 职级解锁 |
|-----|------|---------------|------------|---------|-------------|---------|
| **Free** | 免费 | 无限制(硬≤10) | ≤3(硬≤3) | 1000币 | 30% | 仅实习生 |
| **Pro** | 49元/月 | 无限制(硬≤20) | ≤10(硬≤10) | 5000币 | 20% | 实习生+经理 |
| **Enterprise** | 199元/月 | 无限制(硬≤50) | ≤10(硬≤10) | 20000币 | 10% | 实习生+经理+合伙人 |

**说明**：
- 平台托管席位：理论上无限制，实际由周薪预算决定能雇佣多少；硬封顶为安全网
- 自填API席位：仅自填API模式有数量限制，与平台托管独立计算
- 硬封顶：系统级上限，超出需联系客服（极端情况保护）
- 工资占用：自填API工资按占用比例从周薪预算扣除（如占用30%则1000币工资只扣300币预算）

**3. 投资研究点数 → AI虚拟资金（已更新）**
- 仅属于AI交易员个体，非用户账户资产，用户无个人账户余额概念
- 创建AI时指定，创建后固定不可变更
- 下限统一：10,000（兼顾小额本金用户）
- 上限与订阅层级挂钩：

| 订阅层级 | 投资研究点数上限 | 推荐默认值 |
|---------|-----------------|-----------|
| **Free** | 1000万 | 100万 |
| **Pro** | 1亿 | 500万 |
| **Enterprise** | 10亿 | 2000万 |

- **推荐值机制**：提供保守型/稳健型/激进型三档推荐，引导用户合理配置
- **大额风险提示**：配置≥1亿时提示"大额资金在真实市场可能造成价格冲击，本系统未模拟该效应"
- 不可兑换现金/实物，与工资系统零互通

---

#### 周薪制度（核心扣费机制）

**结算单位**：A股交易日（非自然日）
**结算周期**：5个交易日 = 1周

**扣费时机**：
- **新雇佣**：雇佣时立即扣"本周剩余天数"工资
- **已有AI**：每周一凌晨02:00统一扣下周整周工资

**分时计费规则**（新建AI交易员时）：

| 雇佣时间 | 当日计费 | 说明 |
|---------|---------|------|
| 09:30-11:30 | 全天（1天） | 早盘正常计费 |
| 11:30-14:00 | 半天（0.5天） | 午休时段半价优惠 |
| 14:00-15:00 | 免费（0天） | 午盘后期免费赠送 |

**试用期机制**：
- 长度：固定5个交易日
- 扣费：雇佣时一次性扣5天试用期工资（标准8折，活动3-5折）
- 结束：第5天收盘后提示转正，进入周一扣费周期

#### 用户获取与转化

**免费用户边界**：
- 可体验核心循环（2个AI、基础模型）
- 定期获得"高级AI试用券"（系统赠送或等级奖励）
- 通过试用期体验高级AI，引导订阅转化

**转化漏斗**：
```
免费体验 → 试用期体验高级AI → 订阅Pro解锁更多席位/更高预算
```

**等级系统的作用**：
- 每日登录获得经验值（QQ模式）
- 等级奖励：刷新简历池次数、订阅折扣、试用券
- 高等级用户订阅享永久折扣

### 2.4 用户准入与实名认证 【已冻结】

**准入策略**：彻底拒绝18岁以下用户

#### 用户状态流转

```
游客模式（未登录）
    ├── 可浏览：首页介绍、排行榜（匿名数据）
    ├── 不可创建AI交易员
    └── 引导：点击"创建AI交易员" → 跳转登录

登录后（微信授权）
    ├── 获取用户OpenID
    ├── 强制实名认证（微信realNameVerify接口）
    └── 年龄校验

实名认证后
    ├── ≥18岁：正常使用全部功能
    └── <18岁：拒绝访问，提示"本服务仅限18周岁以上用户"
```

#### 实名认证流程

1. **强制触发时机**：
   - 首次点击"创建AI交易员"
   - 首次点击"我的"页面
   - 首次尝试查看AI决策详情

2. **认证方式**：
   - 调用微信`realNameVerify`接口
   - 获取身份证号，提取年龄信息
   - 服务端记录：`is_verified`, `age`, `id_card_hash`（脱敏）

3. **拒绝处理（<18岁）**：
   - 页面提示："根据相关法规，本服务仅限18周岁以上用户使用"
   - 记录拒绝时间，允许1天后重新认证
   - 不永久封禁账号，仅限制当前认证结果

4. **重新认证机制**：
   - 1天后可再次尝试实名认证
   - 若仍<18岁，继续拒绝并更新拒绝时间
   - 若≥18岁，正常开通全部功能
   - 允许无限次重试，每次间隔1天

#### 游客模式权限

| 功能 | 游客 | 实名用户（≥18岁） |
|-----|------|------------------|
| 浏览首页介绍 | ✅ | ✅ |
| 查看排行榜（匿名） | ✅ | ✅ |
| 创建AI交易员 | ❌ | ✅ |
| 查看AI决策详情 | ❌ | ✅ |
| 邀请好友 | ❌ | ✅ |
| 付费功能 | ❌ | ✅ |

### 2.5 合规声明 【已冻结】

**产品定位声明**：
- 本平台的AI交易决策仅供研究参考，不构成投资建议
- 虚拟交易结果不代表真实投资收益
- 过往收益表现不代表未来收益

**法律合规**：
- 平台内投资研究点数、工资额度不可兑换现金或实物
- 不涉及杠杆交易、T+0等真实市场禁用机制
- 排行榜数据基于历史模拟计算，非投资建议
- 严格限制18岁以下用户访问

**用户协议必备条款**：
- 虚拟交易与真实证券市场的隔离性声明
- 禁止利用平台数据从事非法证券活动
- 平台对异常账户的处置权
- 实名认证为强制性要求

**新闻服务合规**（如适用）：
- 仅展示新闻标题及摘要（≤300字）
- 标注信息来源
- 与合法数据供应商签订授权协议

**界面合规**：
- 所有涉及收益率的页面标注："虚拟交易结果不具有真实投资参考价值"
- 禁用"赚""亏""盈利""暴富"等诱导性词汇
- 使用中性色彩，避免红涨绿跌的强烈视觉刺激

<a name="等级系统"></a>
#### 4.1.1 等级系统

**等级设计**：共30级，细粒度成长，每级均有反馈

**阶段划分**：

| 阶段 | 等级范围 | 称号 | 核心解锁 |
|-----|---------|------|---------|
| 见习期 | 1-6级 | 见习经理 | 基础功能，工资额度缓慢增长 |
| 初学期 | 7-12级 | 初级经理 | 解锁AI决策详情查看 |
| 进阶期 | 13-18级 | 中级经理 | **解锁AI激励功能（积极档）** |
| 高阶期 | 19-24级 | 高级经理 | 解锁激进档，更多特权 |
| 总监期 | 25-30级 | 投资总监 | 全部功能开放 |

**升级经验设计**（每级50-100经验，前期少后期多）：

| 等级 | 所需经验 | 累计经验 | 升级奖励示例 |
|-----|---------|---------|-------------|
| 1→2 | 50 | 50 | 工资额度+2 |
| 2→3 | 60 | 110 | **解锁积极激励档** |
| 3→4 | 60 | 170 | 工资额度+2 |
| 4→5 | 70 | 240 | 解锁新AI模型 |
| 5→6 | 70 | 310 | 称号升级"初级经理" |
| ... | ... | ... | ... |
| 11→12 | 90 | 900 | 解锁持仓实时推送 |
| ... | ... | ... | ... |
| 17→18 | 100 | 1700 | 解锁策略对比分析 |
| ... | ... | ... | ... |
| 29→30 | 100 | 2900 | 满级，解锁全部功能 |

**升级逻辑**：
- 经验值累计达到阈值自动升级
- 升级时即时解锁新功能和工资额度
- 等级只升不降（无降级机制）
- 每级都有明确反馈（工资额度增加或功能解锁）

**付费捷径**：
- 月卡/年卡用户直接解锁至15级（中级经理）
- 付费用户等级不会衰减
- 为付费用户提供"省时间"而非"唯一路径"

**待细化项**：
- [ ] 完整的30级经验值表
- [ ] 每级具体奖励设计
- [ ] 升级时的通知方式
- [ ] 满级后的替代奖励机制

- 工资占用：自填API工资按占用比例扣除周薪预算（如30%占用则1000币工资只扣300币）

**周薪预算**：每周可用于支付AI工资的上限，周一凌晨02:00检查扣费

##### 周薪制度

**基本概念**：
- **周薪周期**：5个交易日 = 1周
- **日薪计算**：日薪 = 周薪 ÷ 5
- **结算单位**：A股交易日（排除周末和法定节假日）

**扣费时机**：

| 场景 | 扣费时间 | 当日计费 | 扣费金额 |
|-----|---------|---------|---------|
| **新雇佣（09:30-11:30）** | 雇佣时 | 全天（1天） | 本周剩余天数 × 日薪（含今天） |
| **新雇佣（11:30-14:00）** | 雇佣时 | 半天（0.5天） | （本周剩余天数-0.5）× 日薪 |
| **新雇佣（14:00后）** | 雇佣时 | 免费（0天） | 本周剩余天数 × 日薪（今天免费） |
| **已有AI** | 每周一 02:00 | - | 下周整周（5天×日薪，长假按实际天数） |

**长假处理**：
- 按实际交易日计算扣费天数
- 例：国庆后首周只有4个交易日，扣4天工资

---

##### 试用期机制

**试用期规则**：
- **长度**：固定5个交易日
- **工资折扣**：标准8折（运营活动可3-5折）
- **扣费**：雇佣时一次性扣5天试用期工资
- **结束**：第5天收盘后提示转正

**转正流程**：
1. 第5天收盘后推送通知"试用期即将结束"
2. 用户选择：立即转正 / 延长试用期（再付5天）/ 解雇
3. 转正后进入周一凌晨扣费周期

---

##### 资金不足处理

**场景1：雇佣时余额不足**
- 硬性拒绝，提示充值

**场景2：周一扣费失败**

| AI类型 | 处理方式 |
|-------|---------|
| **试用期AI** | 立即解雇（不进入欠薪） |
| **正式工** | 进入1周欠薪缓冲期，AI继续工作 |

**场景3：欠薪1周后仍无法支付**
- 按用户设定的优先级解雇AI
- 试用期AI永远是最低优先级

**AI解雇优先级**（用户可设置）：
1. 合伙人（最高，用户可调整）
2. 经理
3. 实习生（正式工）
4. 试用期AI（锁定最低）

#### 4.1.7 自填API模式 【待细化】

**功能定位**：为技术用户提供API自填选项，降低平台成本同时提升自由度

**两种模式对比**：

| 维度 | 平台托管AI（默认） | 自填API |
|-----|-------------------|-------------|
| **API来源** | 平台统一提供（DeepSeek等） | 用户提供自有API Key |
| **策略收集** | 使用平台DeepSeek API（用户无感知） | 使用用户自己的API Key（v1.0双轨制） |
| **工资占用** | 100%标准定价 | 按订阅比例：Free 30%/Pro 20%/Enterprise 10% |
| **席位限制** | 无限制（周薪预算决定） | Free≤3, Pro≤10, Enterprise≤10 |
| **职级解锁** | 按订阅解锁 | 与平台托管一致 |
| **适用人群** | 普通用户 | 技术用户、专业玩家 |

**自填API费用机制**：

1. **工资占用计算**
   - 自填API AI的周薪按占用比例从预算扣除
   - 例：实习生周薪700币，Free用户占用30%，实际扣除210币预算
   - 例：同上周薪，Enterprise用户占用10%，实际扣除70币预算

2. **策略收集双轨制（v1.0）**
   - 平台托管AI：策略收集使用平台DeepSeek API（已含在工资成本中）
   - 自填API AI：策略收集使用用户自己的API Key（成本由用户承担）
   - 未来版本考虑统一策略收集成本模型

**自填API席位限制**：

| 订阅层级 | 自填API席位 | 硬封顶 | 策略收集 |
|---------|------------|--------|---------|
| **Free** | ≤3 | 硬≤3 | 用户自有API |
| **Pro** | ≤10 | 硬≤10 | 用户自有API |
| **Enterprise** | ≤10 | 硬≤10 | 用户自有API |

- 自填API席位与平台托管席位独立计算
- 硬封顶为系统级安全上限，正常情况下不应触发

**用户安全保障**：

1. **免责声明**
   - 用户明确同意平台使用其API Key执行交易决策
   - 平台不承诺API Key的绝对安全，但承诺业界标准加密存储

2. **透明汇报**
   - 每次API调用后记录Token消耗
   - 提供API使用统计面板（日/周/月维度）
   - 预估Token消耗提示（创建AI时给出参考值）

3. **用户自主控制**
   - 停用策略：用户可选3天/7天/10天未登录自动停止使用
   - 余额不足告警：检测到API余额不足时推送提醒
   - 一键删除：随时可删除API Key，立即生效

4. **安全存储**（重点）
   - API Key必须AES-256加密存储
   - 数据库层加密，应用层解密
   - 用户界面仅显示掩码（`sk-...abc123`）
   - 访问日志记录（时间、IP、操作类型）
   - 定期安全审计

**界面交互逻辑**：
- 高级设置区域仅在用户选择"自填API"且验证通过后显示
- 避免干扰普通用户体验

**雇佣时扣费计算**：

```
试用期：

正式工（09:30-11:30雇佣）：
扣费 = 职级周薪 ÷ 5 × 本周剩余交易日数
示例：周四10:00雇佣实习生（周薪700）：
- 本周剩余：周四、周五 = 2天
- 扣费 = 700 ÷ 5 × 2 = 280币
- 下周一02:00扣下周整周700币

正式工（11:30-14:00雇佣）：
示例：周四12:00雇佣实习生（周薪700）：
- 本周剩余：周四（0.5天）、周五 = 1.5天
- 扣费 = 700 ÷ 5 × 1.5 = 210币

正式工（14:00后雇佣）：
示例：周四15:00雇佣实习生：
- 本周剩余：周五 = 1天（周四免费）
- 扣费 = 700 ÷ 5 × 1 = 140币
```

### 4.5 商业化 【待细化】

**关键词**：#月卡 #年卡 #付费 #广告

#### 4.5.1 月卡/年卡特权

**付费权益**（纯虚拟特权）：
- 直接解锁至15级（中级经理），解锁积极激励档
- 等级不会衰减
- 工资额度上限+50%（或更高）
- 解锁旗舰AI模型
- 无广告纯净体验
- 策略文档字数上限提升
- AI对话上下文长度提升
- 多策略对比分析功能
- 持仓实时推送优先体验
- 新模型优先体验权

**定价策略**：
- 【待细化】月卡价格
- 【待细化】年卡价格及折扣
- 【待细化】是否设置单月购买上限（未成年人保护）

#### 4.5.2 广告接入 【已冻结】

**接入条件**：仅对实名认证且≥18岁用户展示

**广告位**：
- banner广告（首页底部）
- 激励视频广告（获取投资研究点数）

**付费用户**：
- 默认不展示广告（无广告纯净体验）
- 不强调"去广告"，而是"专注研究体验"

**暂缓方案**：
- 七日股东推广分成（暂不实施）
- 原因：合规风险需进一步评估
- 决策：v1.x或v2.0再考虑引入
