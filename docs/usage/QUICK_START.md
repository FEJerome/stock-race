# Stock-Race 环境指南

> 当前状态：V3 工程尚未建立，旧四模块运行未核验。本入口只记录已核对的静态事实与环境边界，不把模板补齐视为运行验收。

## 默认开发方向

- V3 使用 TypeScript 严格模式，在 `v3/` 内按 `core / application / adapters / hosts` 分层；首宿主为 Node.js 20+ 本地 Web，CLI 为第二验收宿主。
- `core` 不读取环境变量，不访问 I/O、网络、数据库、系统时钟或随机数。真实模型与数据源均为独立适配器，默认开发和契约测试使用 deterministic fake。
- Local 宿主未来只绑定 loopback；真实模型凭据只能由本地 secret provider 注入，不进入浏览器、AST、快照、日志或证据。当前没有 V3 模型环境模板。
- 旧 `frontend/`、`backend/`、`ai-service/`、`data-service/` 仅作历史实现与移植参考，不是 V3 运行链。

## 当前机器只读核对

- Node.js：24.18.0；npm：11.16.0。满足 V3 的 Node.js 20+ 下限，但尚未用于 V3 安装、构建或测试。
- 默认 Python：3.14.6；另安装 Python 3.10。V3 纯 TypeScript 主链不要求 Python，旧服务的 Python 依赖兼容性未核验。
- `v3/`、V3 `package.json` 和依赖锁文件尚不存在，因此当前没有可复现的 V3 `npm ci`、构建或测试步骤。

首个 V3 工程切片应同时提交实际包清单与锁文件，并在 Windows 上从仓库根目录复现依赖安装和测试后，再把命令记录到本指南。不得把其他项目的安装命令或历史脚本直接搬入本入口。

## 环境文件边界

- 只有根目录及旧四模块的 `.env.example` 可以入库。实际 `.env`、`.env.production`、`.env.test` 等文件只保留在本机，已被 Git 忽略且不得重新跟踪。
- 根 `.env.example` 仅为旧 Compose 插值提供安全占位符，不是 V3 配置，也不是生产部署指南。
- 旧模块模板只描述历史本地接线；外部模型、行情和通知密钥保持空白，外部数据源默认关闭。真实值只能留在本机环境文件，不得复制到对话、日志、测试、文档或提交。
- 模板中的 `__SET_LOCAL_ONLY__` 是必须在本机替换的占位符，不是可用密码。旧服务存在代码内默认值和硬编码密钥风险，不能因模板安全化而视为已经修复。

## 本地数据与探针隔离

- 根 `/v3-data/` 已忽略，用于未来本地快照和运行记录；测试夹具不受该规则影响。真实数据能否提交或公开仍需单独核许可。
- `.local/v3-data-probe-20261027T1605` 是既有隔离数据源探针证据，保持原样，不删除、不复用为 V3 开发环境。
- 不为 V3 预设数据库。旧 PostgreSQL、TimescaleDB、Redis、容器和数据卷不属于默认 V3 启动依赖。

## 仍未验证的事项

1. V3 包清单、锁文件、Windows 安装、构建和测试命令。
2. Local Web/CLI 的实际端口、启动脚本和本地 secret provider。
3. 旧四模块的依赖安装、入口、测试、数据库与服务间接线。
4. 真实模型、真实行情、通知和其他外部接口；这些均需单独授权，不得由模板配置触发默认调用。

历史部署、清库、重置和系统级安装命令仍不得作为当前运行手册执行。
