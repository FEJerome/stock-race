## 当前可用结论

- 本仓库按本地开发项目管理，没有在线生产实例需要维护。
- 主要模块为 `frontend/`、`backend/`、`ai-service/`、`data-service/`；目录存在不代表依赖和接口已经验证。
- 历史要求以 Node.js 20+、Python 3.11+ 为起点，但最终版本与安装步骤须以环境核验结果为准。
- 实际环境文件可能包含历史凭据。环境治理由独立任务完成，只提交安全的 `.env.example`，不提交真实值。

## 在核验完成前

可以进行：

- 阅读代码、依赖清单、测试与配置结构；
- 做不执行历史脚本的静态审查；
- 记录环境缺口和需要验证的命令。

不要默认进行：

- 系统级安装或修改 shell、SSH、Docker 全局配置；
- 安装依赖或启动全部服务；
- 连接外部模型、行情服务或付费 API；
- 创建、清空、迁移或重置数据库；
- 按历史部署文档操作服务器。
