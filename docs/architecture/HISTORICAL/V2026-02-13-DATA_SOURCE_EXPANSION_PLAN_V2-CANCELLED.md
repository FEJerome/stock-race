### 4.2 测试结果判定

| 判定 | 标准 | 后续动作 |
|------|------|----------|
| ✅ 通过 | 所有测试通过 | 纳入混合策略 |
| ⚠️ 待定 | 部分测试通过 | 节后开盘再测 |

### 4.3 预期问题

收盘期间可能遇到的问题：

| 问题 | 原因 | 处理方式 |
|------|------|----------|
| 返回空数据 | 数据源收盘后关闭接口 | 节后开盘重测 |
| 返回静态数据 | 行情冻结 | 节后开盘重测 |
| 响应变慢 | 服务器降配 | 节后开盘重测 |
| 完全无法连接 | 接口维护 | 淘汰或延后 |

**关键原则**: 收盘期间只要能连通且返回有效数据格式，即视为通过，具体能力边界节后开盘再测。

```python
    stock_count = int(5000 * capacity / total_capacity)
```

```python
# 实时健康检查，动态调整
healthy_sources = get_healthy_sources()

    mode = "full_capacity"    # 全容量运行

    mode = "degraded"         # 降级运行，延长间隔
elif len(healthy_sources) >= 2:
    mode = "minimal"          # 最小运行，仅核心股票
else:
```
