## 数据源1: 网易财经

### 调研时间: 2026-02-13
### 调研优先级: 🥇 P0

### 1. 接口可达性

| 项目 | 详情 |
|:---|:---|
| **接口URL** | `http://api.money.126.net/data/feed/{stock_codes}` |
| **请求方式** | GET |
| **认证方式** | 无，无需认证即可访问 |
| **文档来源** | 社区分享/逆向分析，无官方文档 |
| **数据格式** | JSONP（带回调函数 `_ntes_quote_callback`） |

**补充端点：**
- 历史数据: `http://quotes.money.163.com/service/chddata.html?code={code}&start={start}&end={end}`
- 股票搜索: `http://quotes.money.163.com/stocksearch/json.do?count=10&word={keyword}`

### 2. 免费额度

| 项目 | 详情 |
|:---|:---|
| **费用类型** | 完全免费 |
| **频率限制** | 约100-300次/分钟/IP（估算） |
| **日调用上限** | 无明文限制，但频繁请求会触发封禁 |
| **注册要求** | 否，直接可用 |

### 3. 数据质量

| 项目 | 详情 |
|:---|:---|
| **延迟** | A股约5-7秒延迟，港股/美股延迟15分钟 |
| **覆盖范围** | 沪深A股全覆盖，港股（延时）、美股（延时），**不支持北交所** |
| **字段完整性** | 较完整，包含价格、涨跌幅、成交量、成交额、开盘价、最高价、最低价、昨收、买卖五档等 |
| **更新频率** | 秒级更新（A股实时） |

**数据字段示例：**
```json
{
  "code": "0000001",
  "name": "上证指数",
  "price": "3050.23",
  "updown": "15.60",
  "percent": "0.51",
  "open": "3035.12",
  "high": "3060.45",
  "low": "3030.88",
  "volume": "234567890",
  "turnover": "3456789012"
}
```

### 4. 反爬机制

| 机制 | 详情 |
|:---|:---|
| **User-Agent检查** | 有，需要使用浏览器User-Agent |
| **IP频率限制** | 有，高频请求会触发临时封禁（10-30分钟） |
| **Cookie/Session** | 部分端点需要维持Session |
| **验证码** | 异常流量模式可能触发 |

### 5. 技术评估

| 维度 | 评估 |
|:---|:---|
| **加密程度** | 无 |
| **是否需要JS逆向** | 否 |
| **是否需要WebSocket** | 否 |
| **数据格式** | JSONP |
| **开发难度** | 🟢 低 |
| **维护成本** | 🟡 中（API可能变动） |
| **推荐指数** | ⭐⭐⭐⭐ |

### 6. 结论

- **可行性**: ⚠️ **待定**
- **原因**:
  - ✅ 完全免费，无需注册
  - ✅ 数据字段完整，覆盖沪深A股
  - ✅ 技术实现简单，无加密
  - ⚠️ 无官方文档支持，API可能随时变动
  - ⚠️ 存在5-7秒延迟
  - ❌ 不支持北交所股票

3. 复制 `xq_a_token`, `xq_r_token`, `u` 等关键Cookie值

### 2. 免费额度

| **费用类型** | 免费，但需注册账号获取Token |
| **频率限制** | 单IP每分钟20-60次，保守建议控制在20次以下 |
| **并发限制** | 最多5个并发 |

### 3. 数据质量

**核心字段**: symbol, code, name, current, open, high, low, last_close, chg, percent, volume, amount, turnover_rate, pe_ttm, pb, market_capital...

### 4. 反爬机制

**反爬严格程度评级**: ⭐⭐⭐⭐☆ (4/5，严格)

| 层级 | 机制 | 说明 |
|-----|------|------|
| **第一层** | Cookie/Session验证 | xq_a_token服务端校验签名，必须从真实登录获取 |
| **第二层** | 请求头检测 | User-Agent、Referer、X-Requested-With必须合规 |
| **第三层** | IP频率限制 | 单IP每分钟>100次触发临时封禁（10-30分钟） |
| **第四层** | 行为分析 | 检测请求频率模式、访问路径分析、鼠标轨迹检测、指纹检测 |
| **第五层** | 动态Token/加密 | x-sign参数（HMAC-SHA256签名）、x-timestamp防重放、JavaScript混淆、WebAssembly |

**2024-2025反爬升级趋势**:
- 2024年初：新增 `u` 参数验证
- 2024年中：加强JavaScript混淆
- 2024年末：部分接口增加 `x-sign` 签名
- 2025年初：Token有效期缩短至7天

| **是否需要WebSocket** | 否 |

### 6. 结论

- **可行性**: ❌ **放弃**
- **原因**:
  - ❌ 反爬机制极其严格（4/5级），2024年多次升级风控系统
  - ❌ 需要有效的Token管理和请求频率控制
  - ❌ Token有效期短（7-30天），维护成本高
  - ❌ 明确禁止未经授权的商业使用
  - 💡 建议：如确需使用，建议购买官方数据服务（年费通常 ¥50,000-500,000）；对于本项目，性价比不高，建议放弃
