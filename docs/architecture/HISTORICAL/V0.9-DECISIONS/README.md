## 如何阅读ADR

每个ADR文档遵循统一格式：
1. **背景** - 决策的上下文和问题描述
2. **决策** - 最终选择的方案
3. **理由** - 选择该方案的原因
4. **后果** - 该决策带来的影响
5. **替代方案** - 被否决的其他选项
