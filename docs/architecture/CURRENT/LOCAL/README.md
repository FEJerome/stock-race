# Local 形态架构

Local 形态是 **AI股票竞赛平台** 的本地自用版本，用于技术验证和个人使用。

## 产品定位

**一句话描述**: 双击启动，浏览器即用的本地 AI 股票交易研究工具。

**核心价值**:
- 🏠 **零配置自用**: 本地运行，无需注册登录
- 🤖 **多模型对比**: 同时雇佣多个 AI 模型，对比交易表现
- 📊 **完整功能**: 功能对标 Full 版，仅缺少多用户支持
- 🧪 **技术验证**: 验证多数据源、多 AI 模型、实时数据等技术点

## 使用方式

```bash
$ python local.py
Starting Local AI Trading Platform...
Server running at http://localhost:8000
Opening browser... ✓
```

启动后自动弹出浏览器，开箱即用。

### 模块职责

| 模块 | 技术 | 职责 |
|------|------|------|
| **前端** | Vue 3 + Vite | 用户界面、实时行情展示、AI 管理面板 |
| **API 层** | FastAPI | RESTful API、WebSocket、依赖注入 |
| **业务层** | Python | AI 交易员管理、交易引擎、策略收集 |
| **数据层** | SQLite | 本地数据持久化 |
| **采集层** | aiohttp | 多数据源行情采集 |
| **AI 层** | OpenAI SDK | 多模型适配（DeepSeek/通义/Kimi）|

## 与 Full 形态的关系

```
Local（单体）                    Full（微服务）
├── adapters/datasource    ───►  market-data-service
├── adapters/ai            ───►  trading-ai-service
├── core/engine            ───►  trading-service
└── api/routes             ───►  backend (Go)

Vue 前端组件 ─────────────────►  Vue 前端组件（复用）
```

**演进保障**: Local 阶段模块边界清晰 → Full 阶段直接拆分，无需重写业务逻辑。
