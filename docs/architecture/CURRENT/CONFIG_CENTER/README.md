## 配置中心设计原则

### 1. 分层配置原则

```
┌─────────────────────────────────────────┐
│  Layer 1: 配置中心 (Nacos/Apollo)       │  ← 动态配置，热更新
│  • 业务配置                              │
│  • 灰度发布配置                          │
├─────────────────────────────────────────┤
│  Layer 2: 环境变量                        │  ← 部署时配置
│  • 数据库连接                            │
│  • API密钥                               │
├─────────────────────────────────────────┤
│  Layer 3: 本地配置文件                    │  ← 默认配置，降级保护
│  • application.yml                       │
│  • models.yaml                           │
├─────────────────────────────────────────┤
│  Layer 4: 代码默认配置                    │  ← 硬编码保底
│  • 常量定义                              │
└─────────────────────────────────────────┘
```

**优先级**: 配置中心 > 环境变量 > 本地文件 > 代码默认

### 2. 配置分类原则

| 配置类型 | 存储位置 | 更新频率 | 示例 |
|----------|----------|----------|------|
| **动态业务配置** | 配置中心 | 实时 | 模型白名单、功能开关 |
| **环境相关配置** | 环境变量 | 部署时 | 数据库地址、Redis地址 |
| **静态默认配置** | 本地文件 | 版本发布 | 默认模型、默认阈值 |
| **代码常量** | 代码 | 永不 | 最大重试次数、超时时间 |

### 3. 命名规范

```yaml
# 配置Key命名规范
{service}.{module}.{config_name}

# 示例
trading-ai.models.enabled          # Trading AI Service - 可用模型列表
backend.guest-mode.token-ttl       # Backend - 游客Token过期时间
market-data.sources.sina.weight    # Market Data - 新浪数据源权重
```
