# MVP 形态架构

MVP 形态是 **AI股票竞赛平台** 的微信小程序合规验证版本。

## 产品定位

**一句话描述**: 微信小程序上的 AI 股票交易体验，7天免费试用。

**核心价值**:
- 📱 **微信生态**: 小程序即用即走，降低使用门槛
- 🔒 **合规先行**: 实名认证、未成年限制、7天试用
- 🤖 **单一模型**: DeepSeek 快速接入，降低复杂度
- ☁️ **云端部署**: 无需本地配置，即开即用
