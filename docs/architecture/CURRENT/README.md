```
┌─────────────────────────────────────────────────────────────────┐
│                        AI股票竞赛平台                            │
│                     (Three-Form Delivery)                        │
├──────────────┬──────────────┬───────────────────────────────────┤
│    Local     │     MVP      │              Full                 │
│   (自用版)    │  (合规验证版)  │           (商业运营版)              │

│ • FastAPI单体 │ • 单一模型   │ • Go + Python 微服务               │
│ • 多模型对比   │ • 云端部署    │ • 高可用架构                      │
└──────────────┴──────────────┴───────────────────────────────────┘
```

### 形态关系与演进路径

```
Phase 1: Local (当前)
    │
    ├── 验证所有技术点：多数据源、多AI模型、实时数据
    ├── 积累 Vue 组件
    └── 确立模块边界
    │
    ▼
Phase 2: MVP (合规验证)
    │
    ├── 微信小程序接入
    ├── 单一模型(DeepSeek)
    └── 7天试用机制
    │
    ▼
Phase 3: Full (商业运营)
    │
    ├── Local 模块拆分为微服务
    ├── 增加用户/订阅系统
    └── 高可用与性能优化
```

**Local 核心特征**:
- **后端**: FastAPI (Python) 单体服务
- **前端**: Vue 3 + Vite
- **存储**: SQLite (本地文件)
- **部署**: 本地运行 (`python local.py`)
- **目标**: 自用、验证技术、多模型对比
