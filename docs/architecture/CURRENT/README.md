## 形态演进路径

```
Phase 1: Local (当前)
    │
    ├── 验证所有技术点：多数据源、多AI模型、实时数据
    ├── 积累 Vue 组件
    └── 确立模块边界
    │
    ▼
Phase 2: MVP (合规验证)
    │
    ├── 微信小程序接入
    ├── 单一模型(DeepSeek)
    └── 7天试用机制
    │
    ▼
Phase 3: Full (商业运营)
    │
    ├── Local 模块拆分为微服务
    ├── 增加用户/订阅系统
    └── 高可用与性能优化
```

---

## 技术栈对比

| 维度 | Local | MVP | Full |
|------|-------|-----|------|
| **后端** | FastAPI (Python) | 微信云函数 | Go + Gin |
| **前端** | Vue 3 + Vite | 微信小程序 | Vue 3 + 小程序 + App |
| **数据库** | SQLite | 微信云数据库 | PostgreSQL + TimescaleDB |
| **AI 服务** | Python FastAPI | Python FastAPI | Python FastAPI |
| **部署** | 本地运行 | 微信云托管 | Kubernetes |

## 模块边界（三种形态共用）

```
┌─────────────────────────────────────────────────────────┐
│                      前端层 (Vue 3)                       │
├─────────────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────┐  │
│  │  Agent管理   │  │  行情展示    │  │    交易执行      │  │
│  └─────────────┘  └─────────────┘  └─────────────────┘  │
├─────────────────────────────────────────────────────────┤
│                      API 层                              │
├─────────────────────────────────────────────────────────┤
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────────┐  │
│  │ market-data │  │ trading-ai  │  │  news-service   │  │
│  │  -service   │  │  -service   │  │                 │  │
│  └─────────────┘  └─────────────┘  └─────────────────┘  │
├─────────────────────────────────────────────────────────┤
│                    数据层                                │
│              (SQLite / PostgreSQL)                       │
└─────────────────────────────────────────────────────────┘
```

**演进策略**：
- Local：单体部署，模块间函数调用
- Full：微服务拆分，模块间 HTTP/gRPC 调用
