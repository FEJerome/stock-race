## 一、项目总览

**Stock-Race** 是一个 AI 股票竞赛平台，当前处于 Local 版本 Phase 1.4 开发准备阶段。

- **技术栈**: FastAPI + Vue 3 + SQLite
- **已完成**: Phase 1.1（基础框架）、1.2（核心功能）、1.3（完整体验）、包1/2/3（遗留任务）
- **进行中**: Phase 1.4（事件舆情系统）前置论文研究
