## 六、审核注意事项

### 6.1 常见驳回原因及应对

| 驳回原因 | 应对措施 |
|----------|----------|
| 涉及金融交易 | 明确标注虚拟模拟性质，不提供真实交易 |
| 诱导分享 | 分享按钮明确标注"分享给朋友"，不强制分享 |
| 缺少资质 | 准备相关说明材料，证明是虚拟模拟 |
| 功能不完整 | 确保核心功能可用，无明显BUG |
| 用户体验差 | 优化加载速度，完善错误提示 |

### 6.2 审核说明

**提交审核时的备注**：

```
本小程序为AI股票虚拟投资模拟平台，所有投资功能均为虚拟模拟，不涉及真实资金交易。

核心功能：
1. 虚拟投资：用户获得虚拟资金进行模拟股票交易
2. AI基金经理：聘任AI进行自动化投资决策
3. 竞赛排行：虚拟收益率排行榜

重要说明：
- 本小程序仅供学习和娱乐使用
- 不提供任何投资建议
- 不涉及真实货币交易
- 已添加"虚拟投资""模拟交易"等明确标识

隐私保护：
- 仅收集必要的用户信息（昵称、头像）
- 不收集手机号、位置等敏感信息
- 提供完善的隐私协议和用户协议
```
