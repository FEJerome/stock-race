# Stock-Race 图标设计系统

## 设计理念

### 风格定位
**西式复古精英 (Western Vintage Elite)**

融合以下元素：
- **Art Deco 装饰艺术** - 几何线条、对称美学
- **英式绅士俱乐部** - 稳重、优雅、有格调
- **华尔街复古** - 1920年代金融黄金时代
- **现代极简** - 简洁不繁琐，符合当代审美

### 设计关键词
- 优雅 Elegant
- 精致 Refined
- 专业 Professional
- 有趣 Playful (适度)
- 复古 Vintage
- 精英 Elite

### 色彩系统

#### 主色调
```
深海军蓝 (Deep Navy)     #1A365D  - 主色，稳重专业
香槟金 (Champagne Gold)   #D4AF37  - 强调色，复古奢华
象牙白 (Ivory)           #F5F5DC  - 背景色，温和优雅
炭灰 (Charcoal)          #36454F  - 文字色，经典沉稳
```

#### 辅助色
```
勃艮第红 (Burgundy)      #800020  - 上涨/积极
森林绿 (Forest Green)    #228B22  - 下跌/消极（A股风格相反）
古铜色 (Bronze)          #CD7F32  - 装饰元素
```

### 字体风格
- **英文**: Playfair Display, Cormorant Garamond
- **中文**: 思源宋体, 方正清刻本悦宋

### 图形元素

#### 常用符号
- 月桂叶 (Laurel Wreath) - 胜利、荣誉
- 罗马柱 (Column) - 稳固、信任
- 鹰/狮鹫 (Eagle/Griffin) - 力量、远见
- 麦穗 (Wheat) - 丰收、财富
- 齿轮 (Gear) - 工业、效率
- 羽毛笔 (Quill) - 智慧、决策

#### 线条风格
- 细线描边 (1-2px)
- 圆角处理 (柔和不尖锐)
- 对称构图
- 留白充足

## TabBar 图标设计

### 1. 首页 (Home)

**概念**: 古典建筑门廊 + 月桂叶装饰

**设计元素**:
- 三角形屋顶（希腊神庙风格）
- 两根罗马柱
- 底部月桂叶装饰
- 整体对称稳重

**寓意**: 家的感觉，稳固可靠，精英居所

### 2. 行情 (Market)

**概念**: 复古股票行情纸带 + Art Deco装饰

**设计元素**:
- 折线图（上升趋势）
- 两侧装饰性竖线
- 顶部小圆点（数据点）
- 底部装饰边框

**寓意**: 数据驱动，洞察先机，金融专业

### 3. AI经理 (AI Manager)

**概念**: 复古机器人/机械人 + 绅士帽

**设计元素**:
- 圆形头部（简洁）
- 礼帽（精英象征）
- 领结/领带
- 机械齿轮眼睛

**寓意**: 智能与优雅的结合，AI也有格调

### 4. 持仓 (Portfolio)

**概念**: 复古公文包/皮箱 + 文件夹

**设计元素**:
- 矩形公文包轮廓
- 顶部手柄
- 正面扣带
- 侧面厚度表现

**寓意**: 资产管理，专业投资，商务精英

### 5. 设置 (Settings)

**概念**: 复古怀表/罗盘 + 齿轮

**设计元素**:
- 圆形外框
- 中心齿轮
- 四根指针/刻度
- 装饰性边框

**寓意**: 精准控制，时间管理，经典工艺

## 小程序图标设计

### Logo 概念

**主概念**: 智慧猫头鹰 + 月桂环 + 股票折线

**设计元素**:
1. **中心**: 猫头鹰头部（智慧象征）
2. **眼睛**: 两个齿轮（AI元素）
3. **额头**: 上升折线（投资收益）
4. **外围**: 月桂叶花环（胜利荣誉）
5. **底部**: 飘带文字 "EST. 2024"

**色彩**:
- 背景: 深海军蓝 #1A365D
- 主体: 香槟金 #D4AF37
- 点缀: 象牙白 #F5F5DC

**寓意**:
- 猫头鹰 = 智慧、洞察
- 齿轮 = AI、科技
- 折线 = 投资、增长
- 月桂 = 成功、荣誉

## 使用建议

1. **一致性**: 所有图标保持相同线条粗细和风格
2. **识别性**: 即使在小尺寸下也能清晰识别
3. **情感**: 传达专业、可信赖但有趣的品牌形象
4. **适应性**: 在深色和浅色背景下都能良好显示
