## 2. 成本控制架构

### 核心设计：共享内核 + 个性化过滤层

```
【每天一次，全平台共享】
DeepSeek V3 生成"今日大盘全局结构化复盘"
→ 输出 JSON：{大盘, 板块1...N, 概念热点, 情绪指数}
成本：约 0.01–0.02 元/天

【每用户一次，极轻量】
用户标签 → 从 JSON 切片 + 填入人格模板
成本：约 0.001 元/用户（或纯模板渲染，0 成本）
```

### 为什么成本近似 O(1) 而非 O(n)

- **全局分析**：每天 1 次，所有用户共享同一份结构化数据
- **个性化**：主要靠标签做内容筛选和模板渲染，不重新调用大模型
- **"感觉定制化"** 来自人格语气 + 匹配板块，而非每次重新生成

## 4. 与 Local 项目的数据管道

### Local 的价值定位

- **Local = 技术实验室**
- 跑通的新闻舆情采集、事件时序分析（Phase 1.4）可以直接喂给 MVP

### 数据流

```
Local（技术实验室）
  └── 新闻采集 + 事件分析算法
         ↓ 抽取为独立服务/模块
MVP 复盘搭档
  └── 调用结果，生成"今日事件摘要"注入复盘报告
```

### 复用清单

| Local 模块 | MVP 复用方式 | 复用率 |
|-----------|------------|-------|
| AI 适配器（DeepSeek） | 直接复用 | 80% |
| 新闻/舆情采集 | 抽取为数据服务 | 70% |
| 事件分析算法（Phase 1.4） | 抽取为分析服务 | 60% |
| 交易引擎 | 不复用 | 0% |
| 实时行情推送 | 不复用 | 0% |

## 5. 技术栈建议

### 后端

- **FastAPI**（与 Local 一致，便于复用代码）
- **SQLite**（MVP 阶段足够，后续可迁移至云数据库）
- **APScheduler**（定时任务，收盘后触发批量生成）

### 前端

- 微信小程序原生开发
- 或 Taro/Vue 跨端（如需未来扩展 Web 端）

### 部署

- **微信云开发**（快速上线，免运维）
- 或阿里云/腾讯云轻量服务器（更灵活的后端控制）

---

## 6. 关键优化策略

1. **错峰处理**：收盘后夜间（00:30–08:30）批量生成，享受 DeepSeek 低谷优惠，V3 降 50%、R1 降 75%
2. **缓存复用**：重复性人格模板和系统提示词利用缓存命中，降低约 75% 输入成本
3. **分层调用**：日常复盘用 V3，仅高难度推理任务（如复杂策略解析）使用 R1
