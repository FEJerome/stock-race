## 1. 方案概述

### 1.1 设计目标
- **全量覆盖**: 支持A股全部5000+只股票
- **分层延迟**: 中频层10秒，低频层60秒
- **高可用性**: 6数据源冗余，单点故障自动切换
- **生产鲁棒性**: 99.9%可用性，自动故障恢复

### 3.3 故障转移策略

```python
# 三级故障转移
def get_data_with_fallback(symbol, tier="medium"):
    # 1. 尝试主源 (权重最高)
    primary_sources = get_sources_by_weight(tier, limit=2)
    for source in primary_sources:
        data = try_fetch(source, symbol)
        if data and validate_quality(data):
            return data

    # 2. 尝试备用源
    backup_sources = get_sources_by_weight(tier, offset=2, limit=2)
    for source in backup_sources:
        data = try_fetch(source, symbol)
        if data:
            return mark_as_backup(data)

    # 3. 使用缓存数据
    return get_cached_data(symbol, max_age=300)  # 5分钟内缓存
```

## 4. 数据质量保证

### 4.1 多源交叉验证

```python
def cross_validate(sources_data, max_deviation=0.01):
    """
    多源数据交叉验证
    max_deviation: 最大允许偏离1%
    """
    prices = [d['price'] for d in sources_data if d.get('price') > 0]
    if not prices:
        return None, "无有效价格"

    avg_price = sum(prices) / len(prices)

    valid_data = []
    for data in sources_data:
        if data.get('price', 0) <= 0:
            continue
        deviation = abs(data['price'] - avg_price) / avg_price
        if deviation <= max_deviation:
            data['quality_score'] = 100 - deviation * 1000
            valid_data.append(data)
        else:
            data['quality_score'] = 0
            data['anomaly'] = f"偏离{deviation*100:.2f}%"

    return select_best_data(valid_data), valid_data
```

### 4.2 异常检测规则

| 异常类型 | 检测条件 | 处理措施 |
|----------|----------|----------|
| 价格跳变 | |当前-上次|/上次 > 5% | 交叉验证 |
| 零价格 | 价格=0 且 非停牌 | 切换数据源 |
| 延迟过高 | 数据时间<当前-30s | 标记延迟 |
| 成交量异常 | 成交量<前次 | 数据丢弃 |
| 涨跌停 | |涨跌幅| >= 9.9% | 正常标记 |

# 自动降级
if health_score < 50:
    degrade_to_backup_source()

    alert_operator()
