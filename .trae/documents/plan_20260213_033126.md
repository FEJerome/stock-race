# 实现新游客欢迎界面 + 老游客状态检查

## 目标
根据游客账户状态（新游客、老游客数据有效、老游客数据已清空）显示不同界面。

## 游客账户生命周期
- **未创建AI账户**：24小时后账户被清空
- **已创建AI账户**：72小时后账户被清空

## 三种游客状态及处理

### 1. 新游客（首次访问）
- 显示欢迎界面
- 直接进入游客模式

### 2. 老游客 - 数据有效（未过期）
- 建议先进行微信登录（确保账户信息长期保存）
- 可选择继续使用游客模式

### 3. 老游客 - 数据已清空（已过期）
- **未创建AI账户**：直接当做新游客处理（显示欢迎界面）
- **已创建AI账户**：显示数据清空提示页
  - 提示：由于长时间未登录，账户已被清空
  - 建议：进行微信登录，确保后续操作可以长期保存

## 实现步骤

### 1. 后端接口（需要后端开发配合）
- 创建 `GET /api/guest/status` 接口
- 检查游客token状态
- 返回是否过期、是否创建过AI账户等信息

### 2. 前端API封装
- 在 `src/api/guest.ts` 中添加 `checkGuestStatus()` 方法

### 3. 修改 auth store
- 添加 `checkGuestStatus()` 方法
- 添加 `showLoginSuggestion()` 方法（显示建议登录弹窗）
- 修改 `initGuestMode()` 返回详细的游客状态

### 4. 创建欢迎页面
- `src/pages/welcome/welcome.vue`
- 简洁友好的欢迎界面
- 功能介绍和操作按钮

### 5. 创建数据清空提示页
- `src/pages/expired/expired.vue`
- 提示账户清空原因
- 强烈建议微信登录

### 6. 修改 App.vue
- 添加启动时的状态检查逻辑
- 根据不同状态跳转到不同页面

### 7. 更新 pages.json
- 注册新页面

## 判断逻辑流程
```
App启动 → 检查本地 guestSession
  ↓
无 session → 新游客 → 欢迎页
  ↓
有 session → 调用后端检查状态
  ↓
  ├─ 未过期 → 老游客（数据有效）→ 建议登录弹窗
  └─ 已过期 → 检查是否创建过AI账户
               ├─ 未创建 → 当作新游客 → 欢迎页
               └─ 已创建 → 数据清空提示页
```
