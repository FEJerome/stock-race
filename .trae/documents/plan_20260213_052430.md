# 排查小程序空白首页和后端联通问题

## 问题分析
1. 小程序打开后直接进入空白首页，没有任何欢迎界面或提示
2. 需要验证小程序能否正常联通后端服务

## 排查步骤

### 步骤 1：检查 App.vue 启动逻辑
- 查看 App.vue 的 onLaunch 逻辑
- 检查 authStore.token 的初始状态
- 检查是否正确调用 initGuestMode()

### 步骤 2：检查 authStore 持久化配置
- 查看持久化配置是否导致 token 一直存在
- 检查是否影响游客模式初始化

### 步骤 3：检查 Console 日志
- 查看是否有错误信息
- 查看是否有 "App Launch" 日志
- 查看是否有网络请求错误

### 步骤 4：检查 Storage 数据
- 查看本地存储中是否有旧数据
- 检查是否影响游客模式判断

### 步骤 5：验证后端联通
- 检查 Network 标签
- 查看是否有 API 请求
- 检查请求是否成功

### 步骤 6：测试游客模式
- 手动清除 Storage
- 重新编译
- 观察是否跳转到欢迎页

## 可能的问题
1. authStore 持久化导致 token 一直存在
2. initGuestMode() 返回值不符合预期
3. 页面加载失败
4. 网络请求失败
